## What the evolution lab needs from the world (requirements)

- **Walkability map** derived from terrain: water (height < sea level),
  too steep (steepness > threshold, via `CustomTerrain.getSteepness`),
  obstacles (trees/rocks). Agents cannot enter non-walkable cells; steering
  must slide along boundaries.
- **Terrain hints for perception:** what is ahead (water / cliff / open),
  slope, maybe biome.
- **Food sources** from the foliage system (grass detail layer today;
  possibly bushes/fruit trees with regrowth rates per biome).
- **Seeded generation** so a run's world is reproducible.
- Optional: movement cost by slope, drinking at water edges (thirst drive
  → new locus), cover in forests (hiding from predators).

## Current assets in the repo

- `CustomTerrain` façade (heights, steepness, normals, detail layer, tree
  instances, texture alphamaps).
- Brush framework: `TerrainBrush` (heightmap), `InstanceBrush` (tree/object
  placement) + editor tooling.
- Terrain layers (grass, rock, sand, mud) and SpeedTree prefabs
  (broadleaf, conifer, palm).
