AnswerAsync(HttpCaller, IReadOnlyList<BrainRequest>, BrainAnswer) abstract method Sends the requests and fills a row or a failure for each of them.
HealthPath abstract property The path a connection test reads, such as /v1/models or /api/tags (V-60).
TextFor(DecisionQuery) virtual method Gives the text sent for one query: by default the full prompt, ending with this brain's answer instruction. Called on the main thread, so an override may read Unity objects.

In EvoSim: JevBrain, OllamaPointsBrain.

HttpMutatorClient

HttpMutatorClient — abstract class. A mutator model behind a server (10 §2): one chat call per request with the prompt alone (CORE-07, MUT-11), the request's seed and temperature, thinking off. Calls run on the thread pool and fill the reply; the MutatorService caches answers and batches rounds (MUT-14, MUT-31).

Member What it does
Body(MutatorRequest) abstract method The request body for one prompt: nothing but the prompt as the user message (B-11).
ChatPath abstract property The chat endpoint's path, such as /api/chat (Ollama) or /v1/chat/completions.
Content(JToken) abstract method The answer text in a response.
HealthPath abstract property The path a connection test reads, such as /api/tags or /v1/models (V-60).

In EvoSim: OllamaMutatorClient, OpenAIMutatorClient.
