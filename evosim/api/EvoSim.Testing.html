Namespace EvoSim.Testing

Classes

AdvancePending

A wait that ends after a number of Advance(int) calls: how the test fakes answer late (30 §2). In the Freeze wait mode the World calls Wait(), which ends it at once.

AllLayersObstacleSense

A test batched sense that asks for its ray against every physics layer: even so, the views' layer is left out, so what is rendered never changes what animals sense (RAND-11).

AllocationProbe

A test phase placed just before and just after another phase: the pair measures the bytes the main thread allocated in between, every tick (R-07: no allocation per tick in the act phase after warm-up).

BatchProbeAction

A test-only action that wanders and records the group sizes the act phase plans through ActAll (ARCH-12, 20 §10).

BatchProbeLocomotion

A test-only locomotion that records the group sizes the act phase moves through MoveAll (ARCH-12, 20 §10).

BatchProbeSense

A test-only sense that records the group sizes the sense phase reads through ReadAll (ARCH-12, 20 §10).

Blackboard

Shared state for test phases that change "the world" and read it (T-TICK-02): one blackboard is given to several BlackboardPhases, to see which phases see a change.

BlackboardPhase

A test phase that reads the blackboard (logging what it sees), then optionally writes it: only the phases after a writer see the new value in the same tick (T-TICK-02).

CallbackPhase

A test-only phase that runs a callback at its place in the tick (to look at the state between two phases).

CameraProbeSense

A test sense that attaches an "image" (a byte array) to every query, with no cache key unless asked (T-SENSE-10, S24): such queries are never memoised or cached (SENSE-41), and a brain that takes no attachments fails validation (V-51).

CountingCrossover

A test-only uniform crossover that counts its calls (GENE-32: one cross per baby).

DelayedPhase

A test phase that waits, every Every ticks, for an answer that arrives DelayCalls Advance calls after it was asked (like a slow brain); in Freeze mode Wait() delivers it at once.

DoubleDistanceGround

A flat ground whose distance function is twice the Euclidean one: a replaced distance, which every sense and action must then use (T-SPACE-02, SPACE-06).

ExerciseProbe

A finished teaching-path exercise (22 §0) for the Exercises menu tests: a litter that keeps the reference's rule. Its name is not MyLitter, so the menu never takes it for a student's stub.

FakeHttpTransport

A fake server for HTTP brains and mutators (30 §2): answers each request with a scripted function, records every request, can fail, hang until the time-out, or answer late; counts requests in flight at once.

FakeMutator

A test mutator client (30 §2): answers mutation prompts with a scripted function (by default it appends "quickly" to the sentence), records every prompt and batch, and can answer N Advance calls late or fail.

FeedAction

A test-only action: stay, and eat a snack of Energy through a custom interaction that feeds the animal with Feed(Animal, float, bool) (a meal counted like any other).

Fruit

A test-only entity of a kind of one's own: a fruit.

FruitSystem

A test-only entity system for fruit: nothing moves or rots. Several systems of one kind can live in a world ("Apples", "Pears"), and actions find their entities with NearestEntity<Fruit>.

GoToAction

A test action that walks or runs toward a fixed point, stopping at a distance (T-SPACE-01, T-MOVE-01).

Golden

Golden files under Assets/EvoSim/Tests/Golden/ (30 §2): situation texts, prompts, hashes. A missing file is written from the current output (pinned from the first accepted run); an existing one must match exactly. Re-pinning is a deliberate commit that deletes or edits the file and says why.

HookProbe

A test-only species module that counts the births and deaths it hears and adds two statistics columns (probe_born, probe_died, written with the species' prefix in stats.csv).

InvariantPhase

A last phase for test worlds: fails the test on the first broken invariant (30 §5).

Invariants

The checks run after every tick in test worlds (30 §5): positions inside and walkable, no NaN, stats in range, unique ids, no dead or killed animal left, valid actions and rows, populations between floor and cap, carcass portions ≥ 0, genomes of the right length and species.

Lab

The Lab 1 reference species and world as ready-made recipes for tests (04 §5, 08 §7, 09 §3, 14 §2): prey (eat, flee, hide, follow, rest, mate) and predator (hunt, follow, rest, mate) with the prototype's values, founder pools, contrast pairs and prompt texts.

MemoryBrain

A test-only brain with memory: not memoizable, so every deciding animal's query reaches it with its id (even animals in the same situation), and it answers uniform rows.

NeedsEnergyProbe

A test-only module that names a companion it needs with RequiresModuleAttribute: a species without an Energy module gets the warning V-26, whose fix adds one.

ObstacleSense

A test batched sense: one ray along the heading; "blocked" if it hits a collider within 5 m (T-SENSE-09).

OverlayProbeAction

A test-only overlay (ACT-07): done in passing, it plans a walk that must be ignored and a custom interaction that counts the times it applied, per animal.

Place

Puts animals, food items, cover and carcasses at exact positions in a built world (30 §2), so a test sets up the very situation it checks. Records no event.

PondGround

A test ground: flat, with a round pond (not walkable) whose shore animals can reach (samples 22 §2–§3). It answers the water queries that the water sense and the drink action ask.

ProbeAction

A test-only action defined outside the runtime assembly (T-CORE-02): it counts its calls and stays.

ProbeSense

A test-only sense with two tokens; it returns the animal's id parity (T-CORE-02).

RampGround

A test ground: flat for x < RampStart, then a ramp rising at RampSlope (height per meter) (T-MOVE-07).

RandomEventPhase

A test phase that draws from a named stream every tick and records a "probe" event, so the hash depends on the draws.

ScriptedBrain

A test brain (30 §2): answers from a policy written in the test, or from given rows per (species, observation); counts calls and batches; can answer N Advance calls late, fail, or refuse to mix species. Test code only: the system ships no rule-based brain (owner decision).

ShowProbeView

A test-only view that remembers what OnShow told it.

SideCover

A test-only cover: every point with x in [MinX, MaxX] is in cover. Several covers in one world combine (ENV-11).

SlopeLimitLocomotion

A kinematic locomotion that refuses slopes steeper than a limit (T-MOVE-07, after 22 §14).

SnapshotPhase

A test phase that keeps every living animal's genome texts at the end of each tick (T-OUT-02).

SourceScan

Reads the EvoSim source files for static checks (T-RAND-01, T-CORE-08, T-ACT-09): comments removed, line numbers kept.

SpeciesSetup

Adds modules to one species of a world being built: what Species(string, Action<SpeciesSetup>, string) hands to its configure callback.

Stat

Statistical asserts: a proportion or a mean within k standard errors, a χ² uniformity test (30 §2).

SureKillDiet

A test-only diet: every strike kills, and every meal gives exactly Meal energy.

ThrowingPhase

A test phase that throws, for the RAND-20 test: the World stops the run cleanly ("exception in ThrowingPhase") and lets the exception through.

TracePhase

A test phase that writes "tick:name" to a log each time it runs (T-TICK-01).

TraitProbe

A test module declaring one trait (default 60, range [1, 120]) and one capped stat (T-ANIM-02, T-ANIM-03).

TurningLocomotion

A test locomotion that ignores the intent's direction: it turns it by 30° and halves the distance (T-MOVE-06).

WorldBuilder

Builds a world in code, with no scene (30 §2): ground, food, cover, services, phases and species, each added by one chained call, then Build().

WorldFixture

The base class of tests that build worlds: every world started with New(int, WaitMode, string) is destroyed after each test, so tests leave nothing in the scene.

WorldHookProbe

A test-only world service that counts every species' births and deaths and adds one statistics column (world_born, after the species' columns in stats.csv).
