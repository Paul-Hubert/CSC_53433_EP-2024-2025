Remarks

Second phase of the reference tick, after Sense (V-08) and before Choose actions, which waits for the answers. Each decision gets a source: memo (answered earlier in the run), same (another animal of this tick has the same key), cache (the answer cache on disk) or brain (sent now). Batches go out in the order of their first decision, and a brain answers at once or later (BrainAnswer).

A brain that is not memoizable (it has a memory) gets every query: no memo, no sharing, no cache. Under the shuffled control (CTRL-01) the brain reads another living animal's genome, drawn from the species' sampling stream.

Validation checks each species' brain: present and set up (V-10), within its action and prompt limits (V-11), able to read the senses' attachments (V-51).

Reports this phase placed before Sense (V-08), and for each species a missing or unusable brain (V-10), too many actions or too long a prompt for it (V-11), or attachments it can't read (V-51).
