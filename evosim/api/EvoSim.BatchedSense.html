Class BatchedSense

Namespace
EvoSim

A sense that casts rays (line of sight, terrain ahead): it asks for its rays first; the sense phase casts the rays of all deciding animals in one batch, then each sense reads its results (SENSE-30). It must give the same tokens as evaluating it one animal at a time (SENSE-31).

Examples

The test sense ObstacleSense: one ray along the heading, "blocked" if it hits a collider within 5 m.

public class ObstacleSense : BatchedSense
{
    readonly List<string> tokens = new List<string> { "clear", "blocked" };
    public override IReadOnlyList<string> Tokens => tokens;
    protected override string DefaultLabel => "Ahead";

    public override void RequestRays(Animal a, RayBatch rays) =>
        rays.Add(a.Position + Vector3.up * 0.5f, ActContext.HeadingDirection(a.Heading), 5f);

    public override int Read(Animal a, SenseContext s) => s.Rays.Hit(a, this, 0, out _) ? 1 : 0;
}

Remarks

Implement RequestRays(Animal, RayBatch) to add the animal's rays, in a fixed order, and Read(Animal, SenseContext) to read the k-th one back with Hit(Animal, Sense, int, out RaycastHit) through Rays. Nothing else changes: place it under a species like any sense.

The rays never hit the views' layer, so what an animal senses never depends on rendering (RAND-11). Read outside the sense phase, with a context whose rays were not cast, every ray reads as a miss.

Methods

RequestRays(Animal, RayBatch)

Asks for this animal's rays with Add(Vector3, Vector3, float, int); read their results in Read through Rays.

public abstract void RequestRays(Animal a, RayBatch rays)

Parameters

a Animal

The animal that decides this tick.

rays RayBatch

The batch to add rays to; the first ray this call adds is number 0 for this animal and sense.

Remarks

Called by CastRays(IReadOnlyList<Animal>), before any sense reads. Ask for the same rays for the same state, in the same order: Read(Animal, SenseContext) finds them by their number.
