Remarks

Place it under the species and set its trait (a name a module declares), its range and its founder values; GaussianMutation mutates it and clamps the result to the range (MUT-20). It stays out of the prompt unless "show in prompt" is on.

Give the trait a cost, e.g. a metabolism that grows with it: without one the gene drifts to whichever end helps (09 §5, V-47).

Remarks

A founder genome draws each locus uniformly from it, and newcomers below the floor too (POP-03). The World registers the whole pool first, in this order, so founder alleles get the same ids in every run (GENE-21): it must give the same values in the same order every time. The validator reports an empty pool (V-41).
