Examples

Recipe 22 §1, a stat module:

public class Thirst : SpeciesModule
{
    [SerializeField] float perTick = 0.5f, deadly = 100f;
    public StatId Value { get; private set; }
    public float PerTick => perTick;
    public float Deadly => deadly;

    public override void Declare(SpeciesBuilder b) =>
        Value = b.DeclareStat("thirst", StatStart.Fixed(0f), 0f, deadly);

    public override void WritePromptRules(PromptWriter w) =>
        w.Rule($"Thirst grows every step; an animal dies of thirst at {deadly}. Drinking resets it.");
}

Remarks

Derive from it (or from a module kind: Sense, AnimalAction, Gene, DeathRule…) and place the component anywhere under a Species: it belongs to the nearest species above it (ARCH-05). Folders such as Senses or Life are only for order: within a kind, depth-first order is the module's order. A disabled component or an inactive GameObject is absent (ARCH-06).

The World calls, in this order: Declare(SpeciesBuilder) on every module of the species, then Initialize() on every module, then WritePromptRules(PromptWriter) while the prompt is built, then Validate(ValidationReport); during the run, OnBorn(Animal) and OnDied(Animal, string).

A module holds settings only: one module serves every animal of its species, so keep each animal's state in the animal, as a stat or a trait it declares (ANIM-10). Name the modules it needs with RequiresModuleAttribute.

Declare(SpeciesBuilder)

Declare the stats and traits this module needs (before any animal exists).

public virtual void Declare(SpeciesBuilder b)

Parameters

b SpeciesBuilder

The species' declarations: call DeclareStat(string, StatStart, float, float, TraitId) and DeclareTrait(string, float, float, float, bool), and keep the ids they return.

Remarks

Called before any module's Initialize: don't look up other modules here. Two modules may declare the same name: they get the same id, and the first declaration counts (V-38 if they differ).

Initialize()

Look up other modules, layers and species (after every module declared).

public virtual void Initialize()

Remarks

Find things by role or name (ARCH-08): Species.Module<Energy>(), World.Service<Ground>(), Species.Declarations.FindTrait("vision"). Reset your own state here: the same object starts every run.

Reports this module's configuration problems: in the editor, and at the start of a run.

Parameters

Add one message per problem, naming its validator id (V-…) and the object at fault. An error stops the run from starting.

WritePromptRules(PromptWriter)

Lines this module adds to the prompt's rules (PROMPT-01, PROMPT-03).

public virtual void WritePromptRules(PromptWriter w)

Parameters

w PromptWriter

The species' prompt writer: add a line with w.Rule("…").

Remarks

Called while the species' prompt template is built, in module order. The lines go into the prompt's id, its cache keys and the species' results, so keep them stable.
