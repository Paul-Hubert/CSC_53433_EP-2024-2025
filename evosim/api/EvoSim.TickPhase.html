Examples

Recipe 22 §9, a phase placed before Environment that slows regrowth in winter:

public class SeasonsPhase : TickPhase
{
    [SerializeField] int yearLength = 2000;
    [SerializeField] float winterRegrowFactor = 0.2f;
    FoodGrid food;

    public override void Initialize() => food = World.Service<FoodGrid>("Grass");

    public override void Run(TickContext t)
    {
        if (food != null) food.RegrowFactor = t.Tick % yearLength >= yearLength / 2 ? winterRegrowFactor : 1f;
    }
}

A phase that waits for the brains' answers (the Choose actions phase):

public override Pending WaitsFor(TickContext t) => World.Decisions.Pending;

Remarks

Derive from it, implement Run(TickContext), and place the component among the World's phases (the children of its Phases object in the reference scenes): its place there is its place in every tick. Phases run in the same order every tick (TICK-07); a phase with nothing to do returns at once.

A phase changes only what it is responsible for; what it changes is visible to the phases after it in the same tick (TICK-02). It draws random numbers only from named streams (Stream(string), RAND-02) and loops only over ordered lists (RAND-05), so a seed always gives the same run.

A phase that needs answers from a service (brains, the mutator) returns them as a Pending from WaitsFor(TickContext): the World runs it only once they are in (TICK-03).

Run(TickContext)

Do this phase's work for the current tick.

public abstract void Run(TickContext t)

Parameters

t TickContext

The current tick's context: the World, the tick number and the random streams.

Remarks

Called once per tick, after WaitsFor(TickContext)'s work is done. An exception stops the run.

WaitsFor(TickContext)

Work this phase must wait for (brain answers, mutations); null = none (TICK-03).

public virtual Pending WaitsFor(TickContext t)

Parameters

t TickContext

The current tick's context.

Returns

Pending

What must be done before Run(TickContext), or null when nothing is awaited. A Pending already done lets the phase run at once.

Remarks

The World asks before every attempt to run the phase: in Responsive mode, again at every Advance call while the tick waits. Return the same work for the same tick, and don't change the world or draw random numbers here, so both wait modes give the same run (SPACE-14, RAND-11).
