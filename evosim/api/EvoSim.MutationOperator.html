Examples

A number operator, as the MutationOperator script template writes it (values it pushes out of the gene's range are refused at hatching):

public class Nudge : MutationOperator
{
    public override bool Accepts(Gene g) => g.Kind == AlleleKind.Number;

    public override MutationJob StartMutation(Gene gene, Allele parent, RandomStream rng) =>
        MutationJob.Done(parent.Number + (rng.Chance(0.5f) ? 1f : -1f), "nudge");
}

Remarks

Place operators as components under a species (the reference scenes keep them on a Mutation object). At each conception the breed phase picks, for each locus, the first operator that Accepts(Gene) the gene and lists it in OnlyThese, else the first that accepts it and lists no gene (OperatorFor(Species, Gene)). Then, in locus order and from the species' mutation stream, it draws whether the locus mutates with probability Rate (MUT-01), asks MayMutate(Allele), and calls StartMutation(Gene, Allele, RandomStream).

To write an operator, derive from it and implement Accepts(Gene) and StartMutation(Gene, Allele, RandomStream). What it must keep:

  • it sees only the gene and the parent allele, never the animal, its parents or the world (CORE-07);
  • it draws random numbers only from the stream it is given, all of them inside StartMutation(Gene, Allele, RandomStream), as many whatever happens later (MUT-30): the same stream state gives the same job;
  • its result must pass the gene's Check(AlleleValue) at hatching, and a result equal to the parent counts as a failure (MUT-04).

The job may finish at once (Done(AlleleValue, string, string, long?), Failed(string)) or later (Running(Pending), or the MutatorService): the egg hatches only when it is done (MUT-32). See GaussianMutation, LlmMutation and the IntensityLadder sample (22 §8).
