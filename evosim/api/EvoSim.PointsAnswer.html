Points answers to rows (DEC-41): a missing action counts 0, negative points count 0, every action gets +0.01, then the row is normalised, so an all-zero answer becomes uniform. An answer that isn't a JSON object, or points that aren't numbers, are failures (as the prototype's int() raised).
