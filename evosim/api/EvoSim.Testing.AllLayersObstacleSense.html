RequestRays(Animal, RayBatch)

One ray of 5 m along the heading, from 0.5 m above the animal, with every layer in its mask.

public override void RequestRays(Animal a, RayBatch rays)

Parameters

a Animal

The animal that decides this tick.

rays RayBatch

The batch to add rays to; the first ray this call adds is number 0 for this animal and sense.

Remarks

Called by CastRays(IReadOnlyList<Animal>), before any sense reads. Ask for the same rays for the same state, in the same order: Read(Animal, SenseContext) finds them by their number.
