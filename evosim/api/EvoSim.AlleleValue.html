Remarks

Make one with OfText(string), OfNumber(float) or OfVector(ReadOnlySpan<float>). A sentence has its spaces collapsed at once, so "Eat when hungry. " and "Eat when hungry." are the same value. Two values are equal when they have the same kind and the same Canonical(int) form at 4 decimals; the registry compares numbers and vectors at the gene's own precision (GENE-07, GENE-10).

Remarks

Each value is hashed as the 64-bit integer round(v · 10^decimals), little-endian, so the hash doesn't depend on how numbers are written as text. The recorder writes it as vector_sha (13, plan M16 §4 C2).
