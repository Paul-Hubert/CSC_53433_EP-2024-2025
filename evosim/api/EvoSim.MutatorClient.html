Examples

A client that answers at once, simplified from the test client EvoSim.Testing.FakeMutator:

public class QuicklyMutator : MutatorClient
{
    public override string ModelIdentity => "fake-mutator";

    public override MutatorReply Send(IReadOnlyList<MutatorRequest> requests)
    {
        var reply = new MutatorReply(requests.Count);
        for (int i = 0; i < requests.Count; i++)
            reply.SetAnswer(i, FakeMutator.SentenceOf(requests[i].Prompt).TrimEnd('.') + " quickly.");
        reply.ModelCalls = requests.Count;
        reply.Complete();
        return reply;
    }
}

Remarks

A world service: place one under the World next to the MutatorService, which finds it at the start of the run. The service calls Send(IReadOnlyList<MutatorRequest>) on the main thread, with at most one batch out at a time.

What a client must keep: answer every request, at its index, with SetAnswer(int, string) or Fail(int, string), then call Complete() once (or make the reply with a pending that tells when it is complete); send the prompt alone, with the request's model, seed and temperature (MUT-14); never touch Unity objects from another thread. The answers may come at once or later: HttpMutatorClient runs its calls on the thread pool and completes the reply when all are in.
