Examples

T-MUT-11: the first three answers repeat the parent sentence, which the guards reject, so they are redrawn in a second batch.

int calls = 0;
var w = New().Flat(20, 20).Food(0f, 0f).Service<EggSystem>("Eggs")
    .FakeMutation(f => f.Answer = (sentence, seed, prompt) =>
        ++calls <= 3 ? sentence : sentence.TrimEnd('.') + " quickly.")
    .Configure(x => x.Asexual = true).Phase<BreedPhase>().Phase<HatchPhase>()
    .Species("prey", s =>
    {
        s.PreyBody().Action<MateAction>("mate", founders: new[] { "Mate often." }).LifeRules(100, 0).LlmMutation(1f);
        s.Get<Litter>().Configure(3, 3, 40f);
    })
    .Build();
var sp = w.AllSpecies[0];
for (int i = 0; i < 4; i++)
{
    var a = Place.Animal(sp, Place.At(5 + 3 * i, 10));
    a.Age = 200; a.SetStat("energy", 100); a.Choose("mate");
}
w.Advance(1);
CollectionAssert.AreEqual(new[] { 12, 3 }, w.GetComponentInChildren<FakeMutator>().BatchSizes);

Remarks

Add it with FakeMutation(WorldBuilder, Action<FakeMutator>), which also adds the MutatorService it answers for; the Lab1(WorldBuilder, int, int, float, ActOrder, bool, int, int, int) world has one already. The mutation operators and guards stay the real ones: only the model is replaced, so an answer the guards reject is redrawn as usual (MUT-13).
