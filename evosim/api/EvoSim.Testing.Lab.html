The Lab 1 reference species and world as ready-made recipes for tests (04 §5, 08 §7, 09 §3, 14 §2): prey (eat, flee, hide, follow, rest, mate) and predator (hunt, follow, rest, mate) with the prototype's values, founder pools, contrast pairs and prompt texts.

Examples

var w = New(5, name: "hooks").Lab1(prey: 20, predators: 3).Build();
w.Advance(800);
var c = w.FindSpecies("prey").Counters;
Assert.Greater(c.Births + c.DeathsTotal, 0, "something happened");

Remarks

Most members are extension methods on WorldBuilder and SpeciesSetup, so they chain with the builder's own calls. From the smallest to the largest:

  • PreyBody(SpeciesSetup, float, float), PreySenses(SpeciesSetup), PreyActionSet(SpeciesSetup) (and the predator's): one part of a reference species;
  • Ecology(WorldBuilder, float, float, float, Action<SpeciesSetup>, Action<SpeciesSetup>, float): ground, food, cover, carcasses, eggs and both species, with no phase and no brain;
  • Lab1(WorldBuilder, int, int, float, ActOrder, bool, int, int, int): the whole Lab 1 small world (S03), ready to run.

Choose(Animal, string), StatOf(Animal, string) and SetStat(Animal, string, float) help set up one animal after Animal(Species, Vector3, Genome, float, string, Action<Animal>).
