The scene view (21 §5): gizmos for the selected animal (vision, a line to its target, a 1 m circle coloured by action) and, as the overlay's toggles say, food items, cover, carcasses, eggs and a letter per action above each animal (stable colours from the action order). Drawing only reads the world (SPACE-12).

Remarks

It draws in Play mode only, for the current world (Current()). The settings are kept in the editor preferences (EvoSim.Overlay.*), so they survive a restart; EvoSimOverlay edits them.
