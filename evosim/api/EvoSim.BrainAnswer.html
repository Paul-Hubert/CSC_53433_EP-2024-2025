A brain's answer to a batch (DEC-11): one probability row per query, in query order, or a failure per query. Fast brains fill it at once; HTTP brains later, from another thread, then mark it done.

Remarks

Answer now with Now(float[][]). Answer later with Later(int): fill each entry with SetRow(int, float[]) or Fail(int, string), from any thread, then call Complete() exactly once, also when everything failed: the choose-actions phase waits on Pending until then (TICK-03), and in the Freeze wait mode it blocks the main thread.

The choose-actions phase reads each entry with Row(int) and Failed(int), checks it with Check(float[], int), and treats a bad row like a failure.
