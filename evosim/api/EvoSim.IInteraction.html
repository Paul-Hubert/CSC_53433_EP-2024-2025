A custom contact effect (22 §3, drink): applied after moving when the animal is within Reach of the point its action walked or ran to (ACT-10).

public interface IInteraction

Examples

The sample DrinkAction (22 §3) walks to the shore of the nearest water and resets thirst there:

public override void Act(Animal a, ActContext c)
{
    var water = c.Ground != null ? c.Ground.NearestWater(a.Position, c.Vision(a)) : null;
    if (water == null) { c.Search(); return; }
    c.WalkTo(water.Value.Shore, 0f);
    c.OnArrival(new Drink(thirst));
}

sealed class Drink : IInteraction
{
    readonly Thirst thirst;
    public Drink(Thirst t) { thirst = t; }
    public float Reach => 0.5f;
    public void Apply(Animal a, InteractionContext c) { if (thirst != null) a[thirst.Value] = 0f; }
}

Remarks

An action asks for one with OnArrival(IInteraction), usually as a small private class inside the action. The act phase moves the animal, then the interaction resolver calls Apply(Animal, InteractionContext) once, in the same tick, if the animal ended within Reach of the point its intent was heading to (Target; its own position for a stay).

What Apply(Animal, InteractionContext) must keep: it is the only place where an action's effect on animals happens (ACT-06); it draws random numbers only from Stream(Species, string); and nothing checks a diet for it, so check the Diet yourself when the effect is a meal.

Properties

How close the animal must end, after moving, to the point its intent was heading to, in meters. PositiveInfinity applies the effect wherever the animal ends up.
