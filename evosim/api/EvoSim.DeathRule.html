Examples

The sample DiesOfThirst (22 §1): thirst grows in the death phase, and kills at a threshold.

public class DiesOfThirst : DeathRule
{
    static readonly IReadOnlyList<string> causes = System.Array.AsReadOnly(new[] { "thirst" });
    Thirst thirst;

    public override IEnumerable<string> Causes => causes;
    public override void Initialize() => thirst = Species.Module<Thirst>();

    public override string CauseOfDeath(Animal a)
    {
        if (thirst == null) return null;
        a[thirst.Value] += thirst.PerTick;                       // ages with the animal, in the death phase
        return a[thirst.Value] >= thirst.Deadly ? "thirst" : null;
    }
}

Remarks

Derive from it, implement CauseOfDeath(Animal), list every cause it can give in Causes, and place the component under a species. Each tick the death phase first removes killed animals and ages every living animal by one tick (ANIM-35); then it asks the species' death rules, in module order, through CheckAll(IReadOnlyList<Animal>, string[]). The first rule that names a cause for an animal decides: later rules are not asked about it. The phase records the death and removes the animal; the rule only names the cause.

A cause is a short lower-case name, such as starvation: it appears in death events and as the statistics column deaths_<cause>. Draw random numbers only from the species' streams.
