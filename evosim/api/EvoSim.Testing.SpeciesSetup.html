Remarks

Every module goes on its own child GameObject, as in a scene: actions under Actions, senses under Senses, everything else under Life. Order matters (SPEC-03): actions and senses take their order from the calls, which is the order of the probability rows, of the prompt and of the situation text.

The Lab extension methods add whole sets at once: PreyBody(SpeciesSetup, float, float), PreySenses(SpeciesSetup), PreyActionSet(SpeciesSetup) and the predator's.

Action<T>(string, Action<T>, IEnumerable<string>, bool)

Adds an action on its own GameObject, after the actions added so far, with a bound text gene on the same object (GENE-05) unless withGene is false.

public SpeciesSetup Action<T>(string name = null, Action<T> configure = null, IEnumerable<string> founders = null, bool withGene = true) where T : AnimalAction

Parameters

name string

The action's name (its GameObject's name), which Choose(Animal, string) and the prompt use; null = the class name without "Action", in lower case (EatAction gives "eat").

configure Action<T>

Called at once with the new action, to set it up; null = defaults.

founders IEnumerable<string>

The gene's founder sentences, before the neutral "No preference."; null = the neutral one only.

withGene bool

False: no gene, so validation warns (V-05) unless the test wants that.
