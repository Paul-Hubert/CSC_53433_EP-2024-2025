Remarks

EvoSim ▸ Exercises ▸ Replace with stub ▸ 1 RestAction … 14 LlmMutation, in the order of the teaching path (Path). The first time, the menu copies Assets/EvoSim/Exercises/My<Reference>.cs.txt to Assets/Student/Exercises/My<Reference>.cs (with the student assemblies, if missing) and waits for Unity to compile it; after the reload, every instance of the reference module in the open scenes is swapped for the student's class, which is marked [ExerciseOf(typeof(Reference))]. The student then writes the stub, in their own way: nothing grades it, and the conformance suite of its kind (Test Runner, EditMode) only checks that it fits the system.

EvoSim ▸ Exercises ▸ Restore reference puts every reference module back in the open scenes; the student's files stay. Both swaps keep the inspector settings and the component's place, and can be undone (Edit ▸ Undo). Save the scene to keep a swap.
