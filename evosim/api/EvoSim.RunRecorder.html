Class RunRecorder

Namespace

Writes a run into its own folder (13): events.jsonl, stats.csv, alleles.jsonl, final_population.json, summary.json, run_info.json. Events and stats are flushed every 500 ticks, alleles every 5 000 (RAND-22), and every file is written when the run stops, whatever the reason (RAND-20). The compatibility mode writes a two-species world exactly as the prototype does (OUT-05).

Remarks

Place it under the World's Recording object, with a RecordPhase among the phases (V-09). In Begin(), after every module is ready and before the founders, it opens a new folder under OutputRoot (OUT-01), listens to Events, and writes the stats header and run_info.json. The record phase then calls WriteStats(int) and AfterTick(int); when the run stops, OnRunStopped(string) writes alleles.jsonl, final_population.json, summary.json and run_info.json again.

stats.csv columns: t; then per species, with the prefix <species>_, pop, mean_energy, mean_stamina, exhausted, mean_gen, max_gen, births, immigrants, the deaths_… columns, decisions, backend_queries, invalid, portions, one act_<action> per action and its modules' IStatsColumns; alleles after the first species; then the World modules' columns. Counts are cumulative.

The events hash is always computed on the canonical line, so the compatibility mode changes the files, never the hash. The summary's events_hash and events_sha (its first 16 hex digits) identify the run.
