Remarks

The command-line entry points, run from the project folder with the editor closed (or on a copy of the project), each exit Unity with 0 on success, 1 on a failure and, for RunScenario() and RunIntegrity(), 2 on an exception:

  • Unity.exe -batchmode -nographics -projectPath . -executeMethod EvoSim.Batch.RunScenario -scenario S03 [-variant name] [-seed n] [-ticks n] [-responsive]: one scenario (31 §1); each run's files go to Logs/EvoSim/runs/<scenario>-<variant>-s<seed>-<time>/.
  • … -executeMethod EvoSim.Batch.RunRegression: the EditMode tests of category T3 (pinned hashes, equivalences, scene checks); a report Logs/EvoSim/Reports/regression-<time>.txt.
  • … -executeMethod EvoSim.Batch.RunScenarios -tier T2|T3|T4 [-ticks n]: every scenario variant of the tier, each seed twice (same hash); a report Logs/EvoSim/Reports/scenarios-<tier>-<time>.txt.
  • … -executeMethod EvoSim.Batch.RunIntegrity [-checks B-02,B-03] [-brain JEV] [-cpu] [-judge model]: the brain and mutator checks of 32 §2 (Integrity); one JSON and one Markdown report per check under Logs/EvoSim/Reports.

From the open editor, the same code runs through RunScenarioNamed(string, string, int, int, bool) and RunTier(string, int?, out bool) (for instance with the unity CLI's eval), or the Scenario Runner window. A scene that is open in the editor cannot be run: WithScene(string, Func<World, string>) refuses it.

Run(ScenarioAsset, string, int, int?, Action<World>, WaitMode)

Runs one scenario variant and seed in Freeze mode; the recorder writes the run's files.

public static string Run(ScenarioAsset scenario, string variant, int seed, int? ticks = null, Action<World> beforeInitialize = null, WaitMode mode = WaitMode.Freeze)

Parameters

scenario ScenarioAsset

The scenario asset.

variant string

The variant's name; empty or unknown = the first variant.

seed int

The world seed.

ticks int?

The run length in ticks, or null for the scenario's.

beforeInitialize Action<World>

Called on the world after the scenario is applied and before it initialises (tests use it to swap a brain), or null.

mode WaitMode

Freeze (one call advances up to 100 ticks and blocks on the brains) or Responsive (one tick per call, yielding while the brains answer).

Returns

string

A summary line: <scenario> <variant> seed <n> (<mode>): <ticks> ticks, hash <16 hex>, stopped: <reason>, <s> s, model calls …, folder <path>; or a line starting with FAILED: when the scenario can't be applied, the world doesn't validate or the scene is open.

Remarks

The scene is opened additively, the scenario applied (seed, length, brain, overrides, removals), the world initialised and advanced until it stops, then the scene is closed unsaved. The run folder (Logs/EvoSim/runs/<scenario>-<variant>-s<seed>-<time>/) holds run_info.json (with the scenario, variant and applied overrides), events.jsonl, stats.csv, alleles.jsonl, final_population.json and summary.json.

RunRegression()

-executeMethod EvoSim.Batch.RunRegression: runs the EditMode tests of category T3 and exits with their result.

public static void RunRegression()

Remarks

Unity.exe -batchmode -nographics -projectPath . -executeMethod EvoSim.Batch.RunRegression. Each failed test is logged as an error; the totals go to the log and to Logs/EvoSim/Reports/regression-<yyyyMMdd-HHmmss>.txt. Exit code 1 when a test failed, else 0. In the open editor it runs the tests without exiting.

RunScenario()

Command-line entry point: runs one scenario (every seed of it unless -seed is given) and exits.

public static void RunScenario()

Remarks

Unity.exe -batchmode -nographics -projectPath . -executeMethod EvoSim.Batch.RunScenario -scenario S03 [-variant name] [-seed n] [-ticks n] [-responsive]. -scenario is an asset name or the id that starts its title (FindScenario(string)); without -variant the first variant runs; -responsive waits for the brains one tick at a time instead of freezing. Each run logs one summary line (EvoSim scenario: …) and writes its run folder under Logs/EvoSim/runs. Exit code: 0, 1 when a run failed, 2 on an exception.

RunScenarios()

-executeMethod EvoSim.Batch.RunScenarios -tier T2: every variant of that tier (the variant's tier, else the scenario's), each seed run twice; a run fails when it doesn't finish or the two hashes differ (31: exact facts).

public static void RunScenarios()

Remarks

Unity.exe -batchmode -nographics -projectPath . -executeMethod EvoSim.Batch.RunScenarios -tier T2 [-ticks n] (the tier defaults to T2). The result lines go to the log and to Logs/EvoSim/Reports/scenarios-<tier>-<yyyyMMdd-HHmmss>.txt; each run also writes its run folder under Logs/EvoSim/runs. Exit code 1 when a run failed, else 0.
