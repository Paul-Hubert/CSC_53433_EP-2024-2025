The world's events and their running hash (RAND-10). The hash is chained: h0 = SHA-256 of the seeds, h(i) = SHA-256(h(i-1) ‖ UTF-8(line i)), so it can be read after any event.

Remarks

The World creates one per run (Events). Code records an event with Record(SimEvent); every sink (the run recorder, the editor's event log, tests) then receives it with its canonical line. The final hash identifies the run: the same configuration, seeds and answer caches give the same hash (RAND-11).

Record events only from the simulation (phases and modules), in a fixed order: an event recorded from the visuals or in a varying order would change the hash.
