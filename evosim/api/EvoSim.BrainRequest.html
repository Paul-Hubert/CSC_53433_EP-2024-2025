One decision query as an HTTP brain sends it: its place in the batch, the text for the model and the species' action names. Ask(IReadOnlyList<DecisionQuery>) builds it on the main thread; AnswerAsync(HttpCaller, IReadOnlyList<BrainRequest>, BrainAnswer) reads it on the thread pool, so it holds plain values only, no Unity object.
