Inactive views of one species, reused (20 §6): a new animal takes one, a dead one gives it back. Views have no active collider and sit on the "Ignore Raycast" layer, which every sense ray leaves out, so what the animals sense never depends on rendering (SPACE-12, RAND-11).

Remarks

The World makes one pool per species with a Body when the run starts, under a "Views (runtime)" object that is never saved, and calls Take(int) and Return(AnimalView) from its LateUpdate. Main thread only.
