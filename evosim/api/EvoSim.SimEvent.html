Remarks

Build it, add fields with With(string, object), then record it with Record(SimEvent) on Events. The reference kinds are founder, immigrant, birth, death, egg_lost and species_created (13 §3); a module may record kinds of its own.

Use only values CanonicalJson writes the same way every time: numbers, strings, bools, lists and sorted dictionaries of those.
