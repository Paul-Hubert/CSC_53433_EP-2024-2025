Examples

The reference stamina (20 §3.4):

public override void Declare(SpeciesBuilder b)
{
    Max = b.DeclareTrait("stamina.max", max, 1f, 1000f);
    Value = b.DeclareStat("stamina", StatStart.FullTrait(Max), 0f, float.MaxValue, Max);   // capped by stamina.max
}

Remarks

A stat is a per-animal number that changes during life (energy, stamina, thirst); a trait is a per-animal number fixed at birth (vision, stamina.max), which a number gene may set (ANIM-15). Each module declares what it needs in Declare(SpeciesBuilder) and keeps the id it gets back; the animal stores the values in slots, read with a[statId] and a.Trait(traitId).

Two modules may declare the same name: they share one slot, and the first declaration counts. Declarations keeps the result for the run.
