Examples

The sample DrinkAction: relevant when water is in sight.

public override bool IsRelevant(ObservationView o)
{
    var t = o.Token("Water");
    return t != null && t != "none";
}

Remarks

Directed tests hand one to IsRelevant(ObservationView), so an action can say which situations concern it (eat needs food in sight, flee a threat…) without knowing the order of the species' senses.
