Remarks

The sense phase makes one context per world and passes it to every Read(Animal, SenseContext) of the tick; the ask-brains phase reuses it for attachments. It runs first in the tick, so what the context reports is the state before anyone acts.

The queries wrap WorldQueries: never the animal itself, never a killed animal, never one hidden in cover from the asking species, diets checked, ties broken by id (SPACE-08). Pass the animal's vision as the radius (Vision(Animal)) so the sense sees what its actions can reach (ACT-05).

CastRays(IReadOnlyList<Animal>)

Collects the rays of every batched sense for these animals and casts them in one batch (SENSE-30).

public void CastRays(IReadOnlyList<Animal> animals)

Parameters

animals IReadOnlyList<Animal>

The animals that decide this tick, of every species.

Remarks

Called by the sense phase before any sense reads. It clears the previous rays, calls RequestRays(Animal, RayBatch) for each animal and each of its batched senses, then casts them all. A context whose rays were never cast for an animal reports each of its rays as a miss.

NearestAnimal(Animal, AnimalSet, float, IReadOnlyList<Species>)

Finds the nearest visible animal of a set (threats, prey, kin or listed species, from the food web) within a radius (hidden and killed excluded, SENSE-06).

public AnimalHit? NearestAnimal(Animal a, AnimalSet set, float radius, IReadOnlyList<Species> listed = null)

Parameters

a Animal

The animal that senses; never found itself.

set AnimalSet

Which species, seen from the animal's species: Threats, Prey, Kin or Listed.

radius float

How far to look, in meters: usually the animal's vision.

listed IReadOnlyList<Species>

The species for Listed; ignored by the other sets.

Returns

AnimalHit?

The animal found and its distance in meters, or null when none is in range.

Examples

In the Read of a BandedSense, as NearestAnimalSense does:

float vision = a.Trait(Vision);
var nearest = s.NearestAnimal(a, AnimalSet.Threats, vision);
if (nearest == null) return NoneToken;
return TokenFor(nearest.Value.Distance, vision);
