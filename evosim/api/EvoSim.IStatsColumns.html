Interface IStatsColumns

Namespace
EvoSim
Assembly
EvoSim.Runtime.dll

A module that adds columns to stats.csv (13 §4). A species module's columns get its species' prefix and hold that species' values; a world module's columns go at the end of the row, unprefixed. A new column during the run rewrites the header, with empty cells in the rows before it.

public interface IStatsColumns

Examples

// A world service that counts every species' births and adds one column (from EvoSim's test probes).
public class WorldHookProbe : WorldService, IStatsColumns
{
    public int Born;
    static readonly string[] columns = { "world_born" };

    public override void OnBorn(Animal a) => Born++;

    public IEnumerable<string> StatColumns => columns;
    public double StatValue(string column) => Born;
}

Remarks

Implement it on a SpeciesModule (its columns follow the species' act_… columns) or on a WorldModule, a phase or a service (its columns end the row, phases first). The RunRecorder asks for the values when it writes a row, every statsEvery ticks, at the end of the record phase. A column whose name is already in the row is skipped.

StatValue(string) only reads: it must not change the world or draw random numbers.
