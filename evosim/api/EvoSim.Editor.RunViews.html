Class RunViews

Namespace
EvoSim.Editor
Assembly
EvoSim.Editor.dll

Makes a scene watchable (20 §6): a "Run views" object with the ground, entity markers, overlay and capture, and a WorldCamera on the main camera; and the reference bodies (a capsule standing on the ground, a nose that shows where it goes, a marker in the colour of its action). All of them only read the World (SPACE-12).

Remarks

Adds the Run views root with GroundView, EntityMarkers, RunOverlay and RunCapture, and a WorldCamera on the scene's first camera. Components already there are kept. The scene is not saved.

AddToReferenceScenes()

Adds the run views to the six reference scenes and rebuilds the two reference bodies; saves.

[MenuItem("EvoSim/Views/Add Run Views to Reference Scenes")]
public static string AddToReferenceScenes()

Returns

string

One line for the bodies, then one line per scene with what was added.

Remarks

EvoSim ▸ Views ▸ Add Run Views to Reference Scenes. It opens every scene of ScenesFolder additively, adds what is missing, saves the scenes it changed and closes them. The result is logged.
