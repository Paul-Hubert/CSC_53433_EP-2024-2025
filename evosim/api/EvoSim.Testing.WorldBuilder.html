Examples

var w = New().Flat(20, 20).Food(0.1f, 0.01f)
    .Phase<SeasonsPhase>(p => p.Configure(10, 0.2f)).Phase<EnvironmentPhase>()
    .Species("prey", s => s.PreyBody().Action<RestAction>("rest"))
    .Build();
var grass = w.Service<FoodGrid>();
w.Advance(7);
Assert.AreEqual(0.2f, grass.RegrowFactor, "winter");

Remarks

The builder makes the same GameObject tree as a scene: a root with the World, then Environment (layers, entities), Brains (brains, caches, mutators), Phases and one object per species. The tree stays inactive until Build(), so no module runs before the World initialises it.

A world has only what you add: no phase runs unless you add it (Phase<T>(Action<T>), or all of them with ReferencePhases(WorldBuilder, ActOrder)), and no species is populated unless you ask (Population(int), or Animal(Species, Vector3, Genome, float, string, Action<Animal>) after Build). The Lab extension methods add the reference species and the Lab 1 world in one call.

In a test, start builders with New(int, WaitMode, string), which destroys the world afterwards; a builder made with new must be disposed.
