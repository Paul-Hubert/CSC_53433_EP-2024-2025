Remarks

The checks need the model servers running (JEV for the brain; Ollama for B-07, B-10 and the mutator of B-11). Each check opens the scene additively (WithScene(string, Func<World, string>)), so the scene must not be open in the editor, and writes one JSON and one Markdown report under Logs/EvoSim/Reports (IntegrityReport).

Only B-01 is blocking: the others are gates, tracked as trends (32 §2).

Remarks

The run uses the random brain and records every HTTP request of the mutator client; each request must hold only the allowed fields and one user message in the MUT-11 layout, with a deck instruction and a sentence of at most 12 words.

RunIntegrity()

Command-line entry point; exits 1 when a blocking check fails.

public static void RunIntegrity()

Remarks

Unity.exe -batchmode -nographics -projectPath . -executeMethod EvoSim.Integrity.RunIntegrity [-checks B-02,B-03] [-scene Assets/EvoSim/Scenes/Lab1_Small.unity] [-brain JEV] [-cpu] [-judge gemma4:12b]. Without -checks it runs B-01 to B-06, B-08, B-09 and B-11 (B-07 and B-10 only on request). -brain names the brain under test (GameObject name or id); -cpu runs the Ollama points brain on the CPU; -judge is the judge model of B-10. Each check logs one line, EvoSim integrity: …. Exit code: 0, 1 when a blocking check failed, 2 on an exception.
