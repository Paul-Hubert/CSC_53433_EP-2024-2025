Remarks

The World keeps one (Mutations), cleared at the start of each run; the recorder writes it in the run summary (tried, ok, calls, failed, rejected).

Fields

Attempts

Counts of the run. Attempts: mutations started (loci that drew a mutation at conception, MUT-01). Successes: mutations that changed a baby's allele at hatching. ModelCalls: calls to the mutator model, cached answers excluded. CacheHits: answers read from the cache (MUT-14). Failures: mutations that left the inherited allele (MUT-04).
