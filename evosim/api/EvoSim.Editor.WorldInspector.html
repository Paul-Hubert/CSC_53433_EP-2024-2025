Remarks

Unity shows it in place of the default inspector when a World is selected. In Play mode, once the world runs, the buttons Play, Pause, Step, Run N and Stop drive it. The phase list follows the children of the World's Phases object: a toggle switches a phase on or off, ▲ moves it up one place (Edit mode only, with Undo).

Validate runs the validation (ValidationPanel); in Play mode the button shows the report of the world's initialisation. A fix button applies its fix and validates again.

A student who wants an inspector for a module of their own writes the same kind of class: [CustomEditor(typeof(MyModule))] on a class deriving from UnityEditor.Editor, in an Editor folder or editor assembly.
