Returns

The sheet's path, or null when the folder holds no PNG.

Remarks

Call it on the main thread: it uses textures and the GPU. Works in Play mode and in the editor. With more files than max, it takes that many, evenly spaced, the first and the last kept. Every thumbnail has the first image's proportions; empty cells stay dark grey.
