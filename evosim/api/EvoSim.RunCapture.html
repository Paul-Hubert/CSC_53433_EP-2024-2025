Class RunCapture

EvoSim

Saves what the screen shows (overlay included): a PNG when the run starts, every few seconds of real time, and when it stops, into <folder>/<run>/ (the run recorder's folder name), then a contact sheet of them. PNGs are encoded off the main thread. It only reads the World and draws no random numbers (RAND-11).

Remarks

One of the run views: put it on any GameObject of the scene, outside the World (the "Run views" object of the reference scenes). Files are named NNN-tTTTTTT-label.png: the capture's number, the tick, and start, t (periodic) or end.

It needs frames that are drawn: with -nographics it does nothing, and in the editor a hidden Game view draws no frame, so a capture that waited five seconds is given up and counted in Skipped.
