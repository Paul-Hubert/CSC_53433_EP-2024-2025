Examples

A straight-line locomotion, the reference KinematicLocomotion without its random sidestep:

public class StraightLocomotion : Locomotion
{
    public override float Move(Animal a, Intent intent, float staminaBudget, MoveContext c)
    {
        if (intent.IsStay) return 0f;
        float speed = a.Trait(intent.Run ? RunSpeed : WalkSpeed);
        float d = Mathf.Min(speed, Mathf.Min(staminaBudget, intent.MaxDistance));
        var from = a.Position;
        a.Position = c.Ground.SlideTo(from, from + intent.Direction * d);    // never onto non-walkable ground
        return c.Distance(from, a.Position);
    }
}

Remarks

Each species has exactly one locomotion (MOVE-01, V-13); place it anywhere under the species. In the act phase, after the animal's action planned its Intent, the phase calls MoveAll(IReadOnlyList<Animal>, IReadOnlyList<Intent>, MoveContext, Span<float>) for the animals whose intent moves; the default calls Move(Animal, Intent, float, MoveContext) for each one with its stamina budget. Then the metabolism charges the meters Move(Animal, Intent, float, MoveContext) reported, plus ExtraCost(Animal, Vector3, Vector3) (MOVE-06, ANIM-20). No other module assumes the intent was followed exactly.

What an override must keep:

  • change only the moved animal's Position;
  • never end on non-walkable ground or outside the world (MOVE-02): use SlideTo(Vector3, Vector3) or Clear(Vector3, Vector3). The act phase moves an animal back, with a warning, if it does;
  • never move more than the stamina budget (ANIM-21), and read speeds from the animal's traits, never from the settings (ANIM-16);
  • return the meters actually moved, measured with Distance(Vector3, Vector3) (MOVE-06);
  • draw random numbers only from Stream(Species, string).

The sample SlopeLocomotion (22 §14) derives from KinematicLocomotion instead, to refuse steep ground and charge for climbing.

The species' declarations: call DeclareStat(string, StatStart, float, float, TraitId) and DeclareTrait(string, float, float, float, bool), and keep the ids they return.

Called before any module's Initialize: don't look up other modules here. Two modules may declare the same name: they get the same id, and the first declaration counts (V-38 if they differ).
