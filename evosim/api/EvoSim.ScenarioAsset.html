Remarks

Create one with Assets ▸ Create ▸ EvoSim ▸ Scenario. A run is one scenario, one variant and one seed: the runner opens the scene, calls Apply(World, string, int, List<string>) on its World before it initialises, and records what was applied in run_info.json (CFG-03). The scene file itself is never changed.

Paths follow FieldPath: Prey/Litter/max, World/decisionPeriod. Values are written as text, in the invariant culture (0.5, true, an enum name, [8, 4] for a float array).

Apply(World, string, int, List<string>)

Applies the scenario to a World before it initialises: the seed, the length, the brain, the overrides and the removals of a variant. Returns what was applied, for run_info.json (CFG-03); errors are listed in problems.

public SortedDictionary<string, object> Apply(World world, string variantName, int seed, List<string> problems)

Parameters

world World

The World of the opened scene, not initialised yet.

variantName string

The variant to apply (see FindVariant(string)).

seed int

The run seed.

problems List<string>

Receives one line per override, removal or brain that could not be applied.

Returns

SortedDictionary<string, object>

What was applied: brain, each override's path with its value, and remove:<path> for each removal.

Remarks

Order: seed and tick limit; the default brain (the variant's, else the scenario's), found under the World by GameObject name or brain id; the scenario's overrides, then the variant's; then the removals. A problem doesn't stop the rest. Overrides skip the inspector's limits: the World's validation catches values out of range (V-35).
