Class MutatorService

Namespace

Runs LLM mutations (10 §2, §4): every try's instruction and seed are drawn at conception (MUT-30); requests are batched by round — all first tries together, then the redraws of the rejected ones (MUT-31); answers are cached by model, prompt, seed and temperature (MUT-14). It advances only when pumped on the main thread, so the Freeze and Responsive wait modes give the same results.

Remarks

A world service, one per world. It reaches the model through the World's MutatorClient and stores answers in the AnswerCache service when caching is on.

A tick, in order:

  1. in the breed phase, LlmMutation calls Submit(string, int[], long[], string, IReadOnlyList<string>, int) for each mutating text gene; a first try already in the cache is answered at once;
  2. at the end of the breed phase, Flush() sends every queued try as one batch;
  3. in the hatch phase, Pump() reads a finished batch: each answer is cleaned and checked (MUT-12); an accepted answer completes its job, a rejected one queues the job's next try (MUT-13), and the next round goes out at once;
  4. when a due egg's jobs are not done, the hatch phase waits on PendingFor(IReadOnlyList<MutationJob>) (MUT-32).
