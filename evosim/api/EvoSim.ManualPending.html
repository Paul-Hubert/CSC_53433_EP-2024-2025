Examples

A test phase whose answer comes a few Advance calls later (Testing/Probes/DelayedPhase):

pending = new ManualPending(() => { });          // Freeze: Wait() completes it at once
if (World.AdvanceCalls >= readyAtCall) pending.SetDone();
return pending;

Remarks

Whoever does the work calls SetDone() when it is finished, from any thread. With a completion, the Freeze wait mode does the work at once on the main thread; without one, Wait spins until another thread calls SetDone.
