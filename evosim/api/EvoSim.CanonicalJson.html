Writes JSON with sorted keys and fixed number formatting, so equal data gives equal text (RAND-10). Separators follow Python's json.dumps defaults (", " and ": "), the prototype's format.

Remarks

Every event line, and so the events hash, goes through it: changing how a value is written changes every hash. Keys are sorted by ordinal (byte) order.
