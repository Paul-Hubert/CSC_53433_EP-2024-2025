Creating things from the menus (21 §6): a new world with the default tree, a new species with the reference body modules, and actions, senses and genes from the module prefabs in Modules/. The static methods are what the menus call, so tests build worlds exactly as a student does.

Remarks

The menus, in the Hierarchy's right-click menu and in GameObject ▸ EvoSim:

  • New World: a world under the clicked object (or at the root), selected, with Undo.
  • New Species: with a World (or one of its children) selected, a species named Species <n> under it. It has no sense and no action yet: validation asks for one (V-04).
  • Add Action ▸ Eat … Hunt, Add Sense ▸ Energy … Age, Add Gene ▸ Stamina gene: with a Species (or one of its children) selected, an instance of the module prefab under its Actions, Senses or Genes group.

The module prefabs are made by EvoSim ▸ Build Reference Scenes. A student's own module can be added the same way: save it as a prefab in ModulesFolder and call AddModule(GameObject, string, string), or drag the prefab.

AddModule(GameObject, string, string)

Instantiates a module prefab (an action, a sense or a gene) under the species' folder of that kind.

public static GameObject AddModule(GameObject species, string kind, string module)

Parameters

species GameObject

The species object.

kind string

Actions (prefabs at the root of ModulesFolder), Senses or Genes (prefabs in that subfolder); also the name of the group the module goes under, created if missing.

module string

The prefab's file name without .prefab, such as Eat or StaminaGene.

Returns

GameObject

The prefab instance; an action is renamed in lower case, since its name is its name in the prompt.

NewSpecies(GameObject, string)

Remarks

Its groups are Locomotion, Stats, Senses and Actions (empty), Food (a diet of Grass) and Life; it starts with 10 animals and a body. Add senses, actions and genes with AddModule(GameObject, string, string).

NewWorld(string, float)

The default tree (21 §6): ground, environment, brains, recorder and the eleven phases. The random brain is the default, so a new world runs without a model server; JEV is there to switch to.

public static GameObject NewWorld(string name = "World", float size = 48)

Parameters

The World object's name.

Returns

Remarks

It has no species: add one with NewSpecies(GameObject, string). Its decision period is ReferenceDecisionPeriod.
