Remarks

The reference eat action of the prey, and teaching-path exercise 4. Each tick it:

  • finds the nearest food item in sight that its diet grazes (NearestResource(Animal, string)), on every grazed layer, or only on the layer its target names;
  • with none in sight, calls Search() and stops there;
  • stays when the item is within GrazeReach, else walks to it with a stop distance of 0 (MOVE-04);
  • in both cases asks to graze it on arrival (Graze(ResourceItem)), so the animal eats on the very tick it arrives (ACT-10).

With a target of "egg:<species>" it eats eggs instead (22 §15): it walks to the nearest egg of that species its diet eats (NearestEgg(Animal, Species)) and eats it on arrival (EatEgg(Egg)).

Remarks

Called by the act phase, through ActAll(IReadOnlyList<Animal>, ActContext, Span<ActPlan>), once per tick for each animal that chose this action. Look the target up again each tick, so that a moving target is followed (ACT-02). The plan is the last intent and the last interaction the method set; doing nothing means stay.
