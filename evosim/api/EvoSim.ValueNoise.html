Value noise on a lattice: random values at lattice points, smoothly interpolated (the prototype's cover and terrain maps). A noise map is built once from a stream; sampling it is a pure function.

Remarks

Each octave is a lattice of random values in [0, 1) with its own spacing; a sample is the weighted sum of the octaves, each interpolated with a smoothstep. With the default weights (1, 0.5, 0.25…) values lie in [0, 2).
