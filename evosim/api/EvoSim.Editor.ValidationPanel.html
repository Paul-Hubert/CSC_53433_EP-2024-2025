Remarks

Each line reads V-xx text in a help box coloured by severity (error, warning, information). To its right, Select selects and pings the object at fault, and a second button, labelled with the fix (add Rest, sort, clamp…), applies it with Undo.

To offer a fix for a check of your own module, pass a ValidationFix to Error(string, Object, string, ValidationFix) or Warning(string, Object, string, ValidationFix): this panel shows its button.
