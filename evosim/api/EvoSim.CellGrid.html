A grid of square cells over the world rectangle, used inside layers (food cells, cover cells) — never to place animals (02 intro). Finds the nearest marked cell by expanding rings (20 §9).

Remarks

Cells are numbered row by row: cell = z × Width + x, starting at the rectangle's minimum corner. A layer keeps one value per cell in its own array (a bool[] of length Count).

The nearest marked cell, or -1 when none is within the radius.

Remarks

The search visits rings of cells around p and stops once a ring is farther than the radius or the best cell found. It prunes with the straight-line distance, so it assumes the ground's distance is never shorter than that.
