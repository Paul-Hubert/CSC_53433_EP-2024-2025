Remarks

Teaching-path exercise 11. Move(Animal, Intent, float, MoveContext) works in five steps:

  1. a stay moves nothing and returns 0;
  2. the distance is the smallest of the speed trait (speed.run when running, speed.walk otherwise), the stamina budget and the intent's maximum distance;
  3. SlideTo(Vector3, Vector3) goes that far in a straight line, sliding along borders and obstacles;
  4. if that made no progress (less than 1 mm), SideStep(Vector3, float, RandomStream) takes a step of the same length in a random direction (up to 8 tries, else it stays), drawn from the species' actions stream;
  5. it sets the animal's position and returns the distance moved.

Without a ground (some test worlds) it moves straight, with no check.

Methods

Move(Animal, Intent, float, MoveContext)

Moves in a straight line by the smallest of speed, stamina and the intent's maximum distance; slides along obstacles and sidesteps when stuck (MOVE-04).

public override float Move(Animal a, Intent intent, float staminaBudget, MoveContext c)

Parameters

a Animal

The animal to move: set its Position.

intent Intent

What its action wants: direction, walk or run, maximum distance. The act phase only passes intents that move, but return 0 for a stay all the same.

staminaBudget float

The most it may move this tick, in meters (ANIM-21); infinity without a stamina module.

c MoveContext

The ground, the world distance and the random streams.

Returns

float

The meters actually moved, measured with Distance(Vector3, Vector3); 0 when the animal didn't move.
