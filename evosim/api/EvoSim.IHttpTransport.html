Interface IHttpTransport

Sends one HTTP request and returns the response body; throws HttpFailure for an error status. The real one is SystemHttpTransport; tests inject a fake (30 §2) so brains and mutators are tested without servers.

public interface IHttpTransport

Examples

A test gives a JEV brain a fake server instead of a real one:

var fake = FakeHttpTransport.Jev();
jev.Transport = fake;
jev.ConfigureClient("http://jev.test", 5f, 3, 0f, 4);

Remarks

Set a transport through Transport or Transport; null gives back the component's own SystemHttpTransport. HttpCaller wraps it with the time-outs, tries and parallel cap, so a transport sends exactly one request per call.

It is called from the thread pool, several calls at once: an implementation must be thread-safe and must not touch Unity objects. EvoSim.Testing.FakeHttpTransport (scripted answers, failures, hangs) and RecordingTransport (keeps every call) are the implementations to read.
