The real-time visual test from the unity CLI (eval): a headless reference run, a scene set up for Play mode, and the run's status while it plays. Levels: L0 the random brain and no mutation (offline), L1 the scene's brain (JEV) and no mutation, L2 the scene's brain and mutator. Example:

unity command eval --code 'return EvoSim.Editor.RealTimeRuns.Headless("HideVsFlee", 1234, 600, "L2", "RT-L2-headless");'

Remarks

A real-time test compares what a watcher sees in Play mode with a headless run of the same seed:

  • Headless(string, int, int, string, string) (blocks until the end) or HeadlessStart(string, int, int, string, string) and HeadlessStatus() (stepped, for long runs with model calls): the reference run, with its files and hash.
  • PreparePlay(string, int, int, float, string, string, bool, float, string), then Play (the unity CLI's editor_play), then Status() while it plays: the watched run, with the same settings as the Windows player.
  • Behaviour(string, int, int, string): counts, tick by tick, what the watcher should see (hiding, kills, births).

With the editor closed: Unity.exe -batchmode -nographics -projectPath . -executeMethod EvoSim.Editor.RealTimeRuns.FromCommandLine -do headless|behaviour -scene HideVsFlee -seed 1234 -ticks 600 -level L2 [-run NAME] -quit (see FromCommandLine()). Headless runs write their run folder under Logs/EvoSim/runs. The scene must not be open in the editor.

Behaviour(string, int, int, string)

What a watcher should see, counted tick by tick on a headless replay (step 5): hunting predators whose nearest prey in sight is hidden in cover (they lose it), hunters targeting a hidden prey (never), prey hiding in cover, kills, carcass portions, prey meals and food regrown, babies farther than 2 m from both parents.

public static string Behaviour(string scene, int seed, int ticks, string level)

Parameters

A reference scene name; it must not be open in the editor.

The world seed.

ticks int

The run length in ticks.

level string

L0, L1 or L2 (SetLevel(World, string)).

Returns

One line of counts (in animal-ticks unless said), or a line starting with FAILED:.

Remarks

No run files are written. The scene needs species with the ids prey and predator (the Lab 1 scenes, HideVsFlee, Terrain_Locomotion).

FromCommandLine()

Batch entry point (the editor closed): -do headless|behaviour -scene S -seed n -ticks n -level L0|L1|L2 [-run name]; the result line goes to the log and to Logs/EvoSim/realtime-batch.txt (appended).

public static void FromCommandLine()

Remarks

Unity.exe -batchmode -nographics -projectPath . -executeMethod EvoSim.Editor.RealTimeRuns.FromCommandLine -do headless -scene HideVsFlee -seed 1234 -ticks 600 -level L2 [-run NAME] -quit. Defaults: -do headless, -scene HideVsFlee, -seed 1234, -ticks 600, -level L0, -run <scene>-<level>-s<seed>-<ticks>. It does not exit Unity by itself: pass -quit.

HeadlessStart(string, int, int, string, string)

The same headless run, advanced from the editor's update loop a few ticks at a time, so a long run with model calls never blocks a CLI call (the pipeline's timer); poll HeadlessStatus(). The result also goes to Logs/EvoSim/realtime-headless.txt.

PreparePlay(string, int, int, float, string, string, bool, float, string)

Opens a scene for a watched Play-mode run (step 3) without changing it: the settings are kept as a player command line (PlayerArgs) and applied to the World when Play mode wakes it (World.Configuring), as the Windows player does. Enter Play mode afterwards (editor_play); leaving Play mode forgets them.

public static string PreparePlay(string scene, int seed, int ticks, float ticksPerSecond, string level, string runName, bool responsive = true, float captureSeconds = 10, string extra = "")

Parameters

scene string

A reference scene name.

seed int

The world seed (-seed).

ticks int

The run length in ticks (-ticks).

ticksPerSecond float

The pace of the watched run, in ticks per second (-speed).

level string

L0, L1 or L2 (LevelArgs(string)).

runName string

The run folder's name (-run).

responsive bool

True to wait for the brains while Unity keeps rendering; false to freeze (-wait).

captureSeconds float

Seconds between two screen captures (-capture; 0 = start and end only).

extra string

More player arguments, such as -stagger or -minutes 10; empty for none.

Returns

string

<scene> open, unchanged; on Play: <arguments>, or why nothing was prepared.

Remarks

For example unity command --result-only eval --code 'return EvoSim.Editor.RealTimeRuns.PreparePlay("HideVsFlee", 1234, 600, 5f, "L2", "RUN");'. The scene replaces the open scenes, so they must have no unsaved change.
