Class AnswerCache

Namespace
EvoSim
Assembly
EvoSim.Runtime.dll

A persistent store of brain and mutator answers (DEC-33, MUT-14): append-only JSON lines, one file per brain, loaded at the first lookup. Keys hash everything that can change an answer, so a repeated run replays without model calls (RAND-21). Rows are stored with round-trip precision, so a replay is bit-identical.

Remarks

Place one under the World's services. A brain uses it when its UsesCache is on: the ask-brains phase looks each query up with TryGetRow(string, string, out float[]) under the brain's Id, and the choose-actions phase stores good rows with StoreRow(string, string, float[]), never a failure (DEC-34). The mutator stores its texts under "mutator-" and its model's name.

The memo works within one run; this cache works across runs. Delete the folder to forget every answer.
