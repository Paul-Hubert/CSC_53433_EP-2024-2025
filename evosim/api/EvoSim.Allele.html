Remarks

Alleles are made by Register(Gene, AlleleValue, string, string, string, string, long?), once per (locus, value): every animal carrying the same sentence at the same gene shares one Allele object. An allele never changes once registered.

A mutant records the allele it came from (ParentId) and how it was made (Operator, Model, Seed): following parent ids back gives the lineage of a gene down to a founder.
