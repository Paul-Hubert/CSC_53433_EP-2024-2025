Remarks

A world service (the reference scenes name it Eggs); a species that breeds needs one (V-20). The breed phase lays eggs, the hatch phase hatches the due ones, and a lost egg is removed in the environment phase (ENV-22). With the reference incubation of 0, eggs hatch in the tick they are laid.
