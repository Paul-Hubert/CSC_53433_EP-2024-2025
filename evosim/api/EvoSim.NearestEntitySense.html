Remarks

Tokens: the bands and "none", no "here". The default label is "Carcass" whatever the kind: give an egg sense its own label ("Eggs") in the Inspector. For entities of your own kind, write a BandedSense around NearestEntity<T>(Animal, float, Func<T, Animal, bool>).

Remarks

Find things by role or name (ARCH-08): Species.Module<Energy>(), World.Service<Ground>(), Species.Declarations.FindTrait("vision"). Reset your own state here: the same object starts every run.

Read(Animal, SenseContext)

The band of the nearest egg ("egg") or carcass (any other kind) the animal may eat, within its vision; "none" when there is none.

public override int Read(Animal a, SenseContext s)

Parameters

a Animal

The animal that decides.

s SenseContext

The world as it was at the start of the tick: nearest animals, food, cover, distances, rays.

Returns

int

An index into Tokens.

Remarks

Called by the sense phase, through ReadAll(IReadOnlyList<Animal>, SenseContext, Span<int>), for every animal that decides this tick, and by tools (Observe(Animal, SenseContext)). It must give the same token for the same state, draw no random number, change nothing in the world, and learn about other animals only through s, which leaves out hidden and killed ones (SENSE-03, SENSE-06).
