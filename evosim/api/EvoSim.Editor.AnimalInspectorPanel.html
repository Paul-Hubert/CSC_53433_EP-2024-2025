An extra section of the Animal Inspector (21 §4): derive from it in any editor assembly, with a constructor without parameters, and the window draws it under the decision for the animals it shows. The neural species' panel (plan M16 §5) is one.

Remarks

The window makes one instance of each panel class and keeps it. Panels only read the animal and its world (SPACE-12): a run gives the same results with the window open or closed.
