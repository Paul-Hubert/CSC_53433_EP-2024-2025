Remarks

It accepts number genes that give a range (INumberRange, e.g. NumberGene), draws one Gaussian number from the mutation stream and finishes at once with the operator detail gauss. At the edge of the range the clamp may give the parent's value back: the hatch phase then counts the mutation as unchanged (MUT-04).

Properties

Sigma

The standard deviation of the change, in the gene's unit (reference 5); set values below 0 become 0.
