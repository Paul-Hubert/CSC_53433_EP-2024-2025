Namespace
EvoSim

Eggs due this tick hatch, in conception order (REPRO-22), once their genome is complete: the tick waits for the mutator if its answers aren't in (MUT-32, REPRO-24). Each baby starts with the child energy, full stamina, age 0, at its first parent's position (REPRO-12), and a birth event records its litter and mutations (MUT-03).

Remarks

Sixth phase of the reference tick, after Breed (V-08) and before Deaths. With no incubation, eggs laid in the breed phase hatch in the same tick (REPRO-21).

A mutation that failed, did not finish, gives a value the gene does not allow, or changes nothing keeps the inherited allele (MUT-04) and is counted as a rejection. A successful one registers a new allele with its parent, operator, model and seed. No random number is drawn here: every choice was made at conception.

WaitsFor(TickContext)

The mutations the eggs due this tick still wait for (the mutator's or an operator's own work), or null.

public override Pending WaitsFor(TickContext t)

Parameters

t TickContext

The current tick's context.

Returns

Pending

What must be done before Run(TickContext), or null when nothing is awaited. A Pending already done lets the phase run at once.

Remarks

The World asks before every attempt to run the phase: in Responsive mode, again at every Advance call while the tick waits. Return the same work for the same tick, and don't change the world or draw random numbers here, so both wait modes give the same run (SPACE-14, RAND-11).
