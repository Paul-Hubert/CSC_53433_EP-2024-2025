Remarks

The World holds one (World.Decisions), shared by the three decision phases: the sense phase clears it and adds the deciding animals, the ask-brains phase adds the brain answers, and the choose-actions phase waits for Pending, then reads Due. A student who replaces one of these phases uses the same calls.
