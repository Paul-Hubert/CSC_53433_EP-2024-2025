Remarks

Fourth phase of the reference tick, after Choose actions and before Breed. For each animal, in the act order: plan (its current action's ActAll(IReadOnlyList<Animal>, ActContext, Span<ActPlan>) gives an intent and maybe an interaction; busy animals and animals without an action stay), move (its species' MoveAll(IReadOnlyList<Animal>, IReadOnlyList<Intent>, MoveContext, Span<float>)), interact (the InteractionResolver applies graze, strike, scavenge, egg eating or a custom interaction within reach, diet-checked), settle (metabolism and stamina, then the busy countdown).

An animal with an overlay (ACT-07) is planned twice: its action (the carrier) as above, then its overlay in the same context, of which only the interaction is kept. Both interactions apply after the move, the carrier's first; the overlay's countdown drops in settle, and the overlay ends when the animal becomes busy.

The order (ACT-30): in SpeciesInTurn and AllMixed each animal does all four steps before the next one, on the state left by those before it (ACT-31); in Simultaneous every animal plans from the same state, all move, then interactions apply in a random order. Every shuffle comes from the act-order stream (ACT-32); strike rolls and sidesteps use each species' actions stream.

A killed animal is only marked here; it acts no more this tick and dies in the death phase (ANIM-41). If a locomotion leaves an animal on non-walkable ground, the phase puts it back where it started, with a warning (MOVE-02).

Remarks

Look up what you need here, by role or name (Service<T>(), Phase<T>()), and reset your own state: the same object starts every run of the World. A service is initialised before the species' modules; a phase after them.
