Class PromptWriter

Collects the action lines and rule lines that modules contribute to a species' prompt (PROMPT-01). Numbers in rule lines come from placeholders filled from module settings (PROMPT-03): {field} on the writing module, {Module.field} on another module of the species, {species.Module.field} on a module of another species; {name} and {species.name} are display names. A placeholder reads a field or a property; {{ and }} write a brace. A module is named by its class, a base class, or its GameObject.

Examples

A module writes its Inspector text as a rule; the reference prey locomotion's text begins "Animals move {walkSpeed} meter per step. Predators run {predator.Locomotion.runSpeed} meters per step when they hunt," and goes on with "{predator.Stamina.max} stamina against an animal's {Stamina.max}". The sample Thirst writes its number itself:

public override void WritePromptRules(PromptWriter w) =>
    w.Rule($"Thirst grows every step; an animal dies of thirst at {Bands.Number(deadly)}. Drinking resets it.");

Remarks

Build(Species) makes one writer per species when the run starts, and hands it to every module's WritePromptRules(PromptWriter) in hierarchy order (so action lines come in action order), then to every world service's WritePromptRules(Species, PromptWriter). A module calls Action(string, string) or Rule(string); it writes nothing else.

Placeholders keep the prompt true to the world: change a speed in the Inspector and the prompt says the new number (PROMPT-03). The species' header and genes intro, and a frozen prompt, are filled with no writing module: there only {name} and the qualified forms work. {genes}, {situation} and {ask} are left for Fill(string, string, string). An unknown placeholder stays in the text and is reported (V-53).
