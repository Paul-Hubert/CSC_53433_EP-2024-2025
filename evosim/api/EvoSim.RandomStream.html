Examples

var rng = t.Stream(a.Species, "actions");          // "<species id>/actions"
float angle = rng.Range(0f, 360f);                  // degrees
if (rng.Chance(0.3)) { /* ... */ }                  // true 30 % of the time
int pick = rng.Range(0, candidates.Count);          // an index

Remarks

Never make one yourself in simulation code: ask the World's streams for it (Stream(Species, string), For(Species, string)), so the same seed and name always give the same numbers, and draws in one stream never shift another's (RAND-02). Never use UnityEngine.Random or an unseeded System.Random (RAND-01).

Each method's number of draws is fixed, except Range(int, int), which redraws to avoid bias, and Chance(double), which draws nothing for a probability of 0 or 1. Draw in a fixed order, from ordered loops (RAND-05), and a seed repeats the run.
