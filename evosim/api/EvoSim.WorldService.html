Examples

Ground ground;
public override void Initialize() => ground = World.Service<Ground>();

Remarks

Derive from it (or from a service kind: Ground, ResourceLayer, Brain…) and place the component under the World, outside every species. Other modules find it by type with Service<T>(), or by type and name with Service<T>(string): never by a scene reference, so prefabs can be shared (ARCH-08).

Services are initialised before the species' modules and the phases, in hierarchy order, the ground first. See WorldModule for every hook.

Properties

ServiceName

The name other modules use to find this service (ARCH-08): its GameObject's name.

public virtual string ServiceName { get; }

Property Value

string

Remarks

Layers and brains are found by name, so two of them may not share one (V-18).

Methods

WritePromptRules(Species, PromptWriter)

Rule lines this service adds to one species' prompt (PROMPT-01), e.g. a line about a layer that species uses.

public virtual void WritePromptRules(Species species, PromptWriter w)

Parameters

species Species

The species whose prompt is being built.

w PromptWriter

The prompt writer: add lines with its Rule method.

Remarks

Called while each species' prompt template is built, after the species' own modules wrote theirs. Write nothing for a species the service doesn't concern.
