Examples

// Bushes on a 4 m grid that each hold one berry and grow it back (the shape of FoodGrid, cut down).
public class BerryBushes : ResourceLayer
{
    [SerializeField] float regrowP = 0.01f;
    CellGrid grid;
    bool[] berries;
    int count;

    public override int Count => count;

    public override void Initialize()
    {
        grid = new CellGrid(World.Ground.Bounds, 4f);
        berries = new bool[grid.Count];
        count = 0;
    }

    public override bool Nearest(Vector3 p, float radius, out ResourceItem item)
    {
        int c = grid.Nearest(berries, p, radius, World.Ground, out float d);
        item = c >= 0 ? new ResourceItem(this, c, World.Ground.OnGround(grid.Center(c)), d) : default;
        return c >= 0;
    }

    public override bool Consume(ResourceItem item)
    {
        if (item.Layer != this || item.Cell < 0 || !berries[item.Cell]) return false;   // gone already (ENV-02)
        berries[item.Cell] = false;
        count--;
        return true;
    }

    public override void Regrow(RandomStream rng)
    {
        for (int c = 0; c < grid.Count; c++)
            if (!berries[c] && rng.NextDouble() < regrowP) { berries[c] = true; count++; }
    }
}

Remarks

Derive from it, implement Count, Nearest(Vector3, float, out ResourceItem) and Consume(ResourceItem), override Regrow(RandomStream) if the layer grows back, and place the component under the World (reference: "Grass" under Environment) with an Edible. Give the GameObject a unique name: it is the layer's name in diets, senses and random streams, and must not be "world", "act-order" or contain "/" (V-18).

Lifecycle: Initialize() runs after the ground's (build empty storage there); Begin() runs once every module is ready, cover included (place the first items there, with the stream "world/<layer name>"); Regrow(RandomStream) runs once per tick in the environment phase.

Rules to keep: consuming removes the item at once, so two animals never eat the same one (ENV-02); the layer changes only in Regrow(RandomStream) and Consume(ResourceItem), and draws random numbers only from the stream it is given (ENV-03); ties in Nearest(Vector3, float, out ResourceItem) are broken by a fixed key (SPACE-08).
