Examples

The reference FollowAction, without its relevance test:

public class FollowAction : AnimalAction
{
    protected override string DefaultDescription => "move toward the nearest other animal";

    [SerializeField, Min(0f), Tooltip("Stop this far from the followed animal, in meters (reference 1).")]
    float stopAt = 1f;

    public override void Act(Animal a, ActContext c)
    {
        var kin = c.NearestAnimal(a, AnimalSet.Kin);
        if (kin == null) { c.Search(); return; }
        c.WalkTo(kin.Value.Animal, stopAt);
    }
}

Remarks

Derive from it, implement Act(Animal, ActContext) and DefaultDescription, and place the component on its own GameObject under a species. The GameObject's name is the action's name; the depth-first order of the species' actions is their order in the prompt and in the brain's answer (SPEC-03). A TextGene on the same GameObject, or on a child of it, is bound to it (GENE-05).

Once the brain chose it, Act(Animal, ActContext) runs every tick until the next decision, or until the animal becomes busy or dies (ACT-02). An action done in passing (a call) is an Overlay: it runs beside a second, moving action (ACT-07). What Act(Animal, ActContext) must keep:

  • Plan only through the ActContext: never set the position, stats or flags of any animal (ACT-06). Effects on others go through interactions, which check the reach and the diet.
  • Target only what the context's queries return: what the animal's senses could report (ACT-05).
  • With nothing to act on, call Search() (ACT-04).
  • Never read gene sentences: genes reach an action only through traits (ACT-20).
  • Draw random numbers only from the species' streams (World.Random.For(Species, "actions")), never from UnityEngine.Random, so that a seed repeats a run.

Examples

A scent mark left in passing:

public class MarkAction : AnimalAction
{
    public override bool Overlay => true;
    protected override string DefaultDescription => "leave a scent mark; you also do your next choice";

    public override void Act(Animal a, ActContext c) => c.OnArrival(new Mark());   // no intent: the carrier moves
}

Remarks

The carrier is drawn from the same probabilities with every overlay set to 0, so it is what the animal would have done without the overlay (DEC-20). Each tick the carrier plans the intent and its interaction as usual; then the overlay's Act(Animal, ActContext) runs in the same context: its intent is ignored (the carrier moves the animal) and its interaction applies after the carrier's, measured from the point its own intent names (07 §3). It acts for OverlayTicks ticks, and ends when the animal becomes busy or dies.

An overlay must not call Search() or Wander(): its intent is thrown away. It may not mate or hunt (V-27), and a species needs at least one action that is not an overlay (V-19).

Methods

Act(Animal, ActContext)

Every tick while this action is chosen: say where to go, and what to do on arrival (ACT-02, ACT-03).

public abstract void Act(Animal a, ActContext c)

Parameters

a Animal

The animal that acts: alive and not busy.

c ActContext

The context to query and plan through; Begin(Animal) was already called for a.

Remarks

Called by the act phase, through ActAll(IReadOnlyList<Animal>, ActContext, Span<ActPlan>), once per tick for each animal that chose this action. Look the target up again each tick, so that a moving target is followed (ACT-02). The plan is the last intent and the last interaction the method set; doing nothing means stay.

ActAll(IReadOnlyList<Animal>, ActContext, Span<ActPlan>)

The batch entry point (20 §10, ARCH-12): the act phase plans every animal of the group (all chose this action) through it. The default calls Act for each; an override must give the plans Act would give.

public virtual void ActAll(IReadOnlyList<Animal> group, ActContext c, Span<ActPlan> plans)

Parameters

group IReadOnlyList<Animal>

The animals to plan, all of which chose this action: one animal in the sequential act orders, every such animal in the simultaneous one (ACT-30).

c ActContext

The shared context; call Begin(Animal) before planning each animal.

plans Span<ActPlan>

Where to write each animal's plan, at the same index as in group.

Remarks

Override it only to plan many animals at once (a job, a batched query). The single-animal Act(Animal, ActContext) stays the readable reference: the override must give the same plans, with the same random draws, and pass the same conformance tests.
