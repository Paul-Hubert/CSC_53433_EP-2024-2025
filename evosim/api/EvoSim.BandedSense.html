Examples

The sample NearestWaterSense (22 §2):

public class NearestWaterSense : BandedSense
{
    protected override bool HasHere => true;
    protected override string DefaultLabel => "Water";
    protected override string HereSentence() => "I am at the water's edge.";

    public override int Read(Animal a, SenseContext s)
    {
        if (s.Ground == null) return NoneToken;
        float vision = s.Vision(a);
        var water = s.Ground.NearestWater(a.Position, vision);
        return water == null ? NoneToken : TokenFor(water.Value.Distance, vision, here: water.Value.Distance <= 0.5f);
    }
}

Remarks

Derive from it to sense the distance to anything: implement Read(Animal, SenseContext) with a SenseContext query and return TokenFor(float, float, bool) or NoneToken; override HasHere for a "here" token and HereSentence() for its V2 text. The base class declares the "vision" trait, builds the token list in Initialize(), writes both text styles and validates the bands.

The texts state the vision trait's default (StatedVision), not each animal's own vision, so one token always gives one text (SENSE-10).

Remarks

The species joins the fragments of its senses with spaces (Describe(Observation, TextStyle)). The text depends on the token only, never on the animal, so the same observation always gives the same text: the answer cache keys on it. Override it for V2 sentences or to state a range in meters (SENSE-12, SENSE-13).
