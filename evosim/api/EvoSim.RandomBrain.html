Remarks

The reference of teaching-path exercise 13 (MyRandomBrain, 22 §0). What it does: its Id is "random"; Ask(IReadOnlyList<DecisionQuery>) makes one row per query, in query order, with one entry per action of that query's species, each 1/n (Uniform(int)), and answers at once with Now(float[][]). It reads neither the genes nor the situation, and keeps every default (memoizable, any number of actions, species mixed in one batch, no cache).

Random hunters can't feed themselves: the gap between this brain and a real one shows that the brain matters. It is also the brain of fast tests.

public override BrainAnswer Ask(IReadOnlyList<DecisionQuery> batch)

Parameters

batch IReadOnlyList<DecisionQuery>

The queries the memo and the cache could not answer, at most one per memo key (DEC-32); never empty.

Returns

BrainAnswer

One row or one failure per query, in query order: Now(float[][]) when every row is ready, or Later(int) filled from another thread, then completed.

Remarks

Called on the main thread by the ask-brains phase, once per tick and per batch. Read only the queries: a row must depend on the query alone (DEC-12), and the brain must not change the world (CORE-06). A query it can't answer is marked with Fail(int, string), never answered with a made-up row.
