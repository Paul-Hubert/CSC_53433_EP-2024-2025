The queries senses and actions share (ACT-05, SENSE-06): within the animal's vision, never itself, never a killed animal, never an animal hidden from it in cover, diets checked. Ties by id (SPACE-08).

Examples

var threat = World.Queries.NearestAnimal(a, AnimalSet.Threats);   // within a's vision
if (threat != null && threat.Value.Distance < 5f) { /* ... */ }

Remarks

Reach it with Queries; senses usually call it through their SenseContext and actions through their ActContext. Using the same queries is what keeps an action from targeting something its senses could not report (ACT-05).

Every query only reads the world. Results are null when nothing is found.
