Remarks

Unity shows it below the Species' own fields when a Species is selected. In Edit mode, press Show the computed tables: it validates the world (which prepares it) and fills the tables; in Play mode they show the running world. The validation panel ends the inspector, with its fix buttons.

The prompt preview: pick a brain, a founder genome (the n-th founder of each gene), a text style (V1 or V2) and one token per sense (or Random situation), press Build, and read the exact prompt with its token estimate and the brain's limit; Copy puts it on the clipboard.
