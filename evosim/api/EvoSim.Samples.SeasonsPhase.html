Remarks

What it adds. Seasons: a year of yearLength ticks whose first half is summer (regrowth as set on the food layer) and second half winter (regrowth times winterRegrowFactor).

Mechanism. A TickPhase: Initialize() finds the food layer once, Run(TickContext) runs every tick at its place in the phase list and changes one setting of the layer, which the environment phase then uses (TICK-02). Validate(ValidationReport) checks the layer exists and the phase order (V-20, V-08).

In a scene. Add it on a new GameObject among the World's Phases children, before Environment: phases run in hierarchy order (TICK-01).
