Examples

A number gene kind, as the Gene script template writes it (the trait must be declared by a module of the species):

public class CourageGene : Gene
{
    [SerializeField, Tooltip("The trait this gene sets.")] string trait = "courage";
    [SerializeField, Tooltip("Founder values.")] List<float> founders = new List<float> { 1f };

    public override AlleleKind Kind => AlleleKind.Number;

    public override IReadOnlyList<FounderAllele> FounderPool
    {
        get
        {
            var pool = new List<FounderAllele>();
            foreach (var f in founders) pool.Add(new FounderAllele(AlleleValue.OfNumber(f), "founder"));
            return pool;
        }
    }

    public override void Express(AlleleValue value, Expression e) => e.SetTrait(trait, value.Number, false);
}

Remarks

A gene is a component under a species. Its place among the species' genes (depth first in the hierarchy) is its locus, Locus: the index of its allele in every Genome of the species (GENE-06). A text gene on or under an action is bound to that action and takes its name as label (GENE-05).

To add a gene kind, derive from it and implement Kind, FounderPool and Express(AlleleValue, Expression). Override Check(AlleleValue) to refuse some values, MayMutate(Allele) to protect some alleles, Decimals to compare numbers at another precision, and ReadByBrain when the brain should read it. A number gene kind should also implement INumberRange, so that GaussianMutation and the random-founders control (CTRL-01) work with it.

What a gene kind must keep: it holds settings only, never per-animal state; FounderPool gives the same values in the same order in every run (GENE-21); Express(AlleleValue, Expression) acts only through the Expression it is given and draws no random number.

Remarks

A founder genome draws each locus uniformly from it, and newcomers below the floor too (POP-03). The World registers the whole pool first, in this order, so founder alleles get the same ids in every run (GENE-21): it must give the same values in the same order every time. The validator reports an empty pool (V-41).
