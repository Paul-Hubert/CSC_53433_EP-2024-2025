Remarks

Place it under the World's Environment object, as the "Carcasses" GameObject. A successful strike calls Create(Animal, int) on the first carcass system of the World; a scavenging interaction calls EatPortion(Carcass, Animal). The environment phase counts lifetimes down and removes rotten or used-up carcasses (ENV-22).

Removed carcasses go back to a pool and are reused, so a kill allocates nothing (R-07). A subclass that overrides OnRemoved(Carcass, string, TickContext) must call the base method to keep the pool.
