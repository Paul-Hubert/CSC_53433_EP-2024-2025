Remarks

Create one with Assets ▸ Create ▸ EvoSim ▸ Allele Pool and set it as the pool of one or more TextGene components: each of them then takes its founder sentences from the asset, and its contrast sentences too when the asset's are not empty. The neutral allele stays a setting of each gene.

Fields

A sentence that pulls the action, used only to test brains (GENE-23); empty = each gene's own.
