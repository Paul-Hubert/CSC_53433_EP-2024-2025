Examples

One baby per conception whatever the energy, as in the prototype before 2026-10-09 (setting Min = Max = 1 does the same):

public class OneBaby : Litter
{
    public override int Size(RandomStream rng, float[] parentEnergies) => 1;
}

Remarks

The breed phase finds it by type (Species.Module<Litter>()), so a replacement derives from it. At each conception it calls Size(RandomStream, float[]); each parent then pays ChildEnergy / (number of parents) × k energy (REPRO-11), and each baby hatches with ChildEnergy. The Block cap rule may cut k further. Without a Litter, a conception makes one baby and costs nothing (V-26 warns).

The reference Size(RandomStream, float[]), step by step (the exercise MyLitter rewrites it):

  1. k = rng.Range(Min, Max + 1): uniform in [Min, Max], one draw;
  2. share = ChildEnergy / number of parents;
  3. affordable = the smallest floor(energy / share) over the parents (no limit when share is 0);
  4. the result is max(Min, min(k, affordable)): what the poorest parent can pay, but never below Min, so a parent can end with zero or less energy.
