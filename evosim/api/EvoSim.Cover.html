Examples

// Every point with x in [MinX, MaxX] is in cover (a test probe of EvoSim).
public class SideCover : Cover
{
    public float MinX = float.NegativeInfinity, MaxX = float.PositiveInfinity;

    public override bool InCover(Vector3 p) => p.x >= MinX && p.x <= MaxX;

    public override bool NearestCover(Vector3 p, float radius, out Vector3 point, out float distance)
    {
        point = new Vector3(Mathf.Clamp(p.x, MinX, MaxX), p.y, p.z);
        distance = Mathf.Abs(point.x - p.x);
        return distance <= radius;
    }
}

Remarks

Derive from it, implement InCover(Vector3) and NearestCover(Vector3, float, out Vector3, out float), and place the component under the World (the reference: CoverLayer on "Thickets", under Environment). Several covers combine: an animal is hidden when any of them hides it (IsHiddenFrom(Animal, Species)).

A hidden animal is left out of its hunters' senses, can't be targeted by their actions and is never struck (ENV-11). Override Hides(Species, Species) to change who hides from whom. Cover only answers questions: it draws no random number after Initialize(), which may build a map from a "world/…" stream.

Whether an animal of hidden standing in cover is hidden from from: the reference hides a species from its threats; kin and its own prey still see it (ENV-11).

Remarks

The default also requires hidden to be one of the hiding species when that list is set. An override must give the same answer for the same pair of species during a run: senses rely on it.
