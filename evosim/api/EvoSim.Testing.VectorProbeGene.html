Class VectorProbeGene

Namespace
EvoSim.Testing
Assembly
EvoSim.Testing.dll

A free vector gene for tests (plan M16 §4 C6): a few founder vectors of fixed length, values within ±Clamp; sets no trait and writes nothing into the prompt. The T-MUT suite puts it beside a text and a number gene, so an operator may accept any of the three kinds (30 §4).

FounderPool

Three founders: 0.1·(i + 1), its negative, and 0.25·(−1)^i.

public override IReadOnlyList<FounderAllele> FounderPool { get; }

Property Value

IReadOnlyList<FounderAllele>

Remarks

A founder genome draws each locus uniformly from it, and newcomers below the floor too (POP-03). The World registers the whole pool first, in this order, so founder alleles get the same ids in every run (GENE-21): it must give the same values in the same order every time. The validator reports an empty pool (V-41).

Remarks

The hatch phase checks every mutant with it, whatever operator made it: a refused mutant leaves the inherited allele and is counted as not allowed. Text genes also check their founders with it (V-40).

Express(AlleleValue, Expression)

Sets no trait: the probe is only carried and mutated.

public override void Express(AlleleValue value, Expression e)

Parameters

value AlleleValue

The allele's value.

e Expression

The target: call SetTrait(string, float, bool) for a trait, PromptGene(string, string) for a line of the genes block.

Remarks

Called at birth with the newborn (prompt lines are then dropped), and each time a decision's genes block is written, with no animal (traits are then dropped), for the genes the brain reads. Act only through e.

Initialize()

Forgets the founder pool, so a changed Length takes effect.

public override void Initialize()

Remarks

Find things by role or name (ARCH-08): Species.Module<Energy>(), World.Service<Ground>(), Species.Declarations.FindTrait("vision"). Reset your own state here: the same object starts every run.
