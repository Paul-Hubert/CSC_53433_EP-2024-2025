The named random streams of one world (RAND-02…04). Asking twice for a name returns the same stream. Map layers use "world/<layer name>", so adding a layer never changes another layer's map.

Examples

var regrowth = World.Random.Get(layer.StreamName);                 // a world stream
var map = World.Random.Get("world/" + ServiceName);               // the map: uses the world seed
var litter = World.Random.For(species, "litter");                 // "<species id>/litter"

Remarks

The World makes a new set at each Initialize, from its seed and world seed (Random). Streams are per purpose and, where a species is involved, per species (RAND-03): <species>/founders, /sampling, /actions, /litter, /mutation, /migration; world streams act-order, a layer's name for its regrowth, and world or world/<layer> for the map.

A new purpose of your own is just a new name: it gets its own stream and shifts no other.
