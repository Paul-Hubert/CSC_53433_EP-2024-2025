Examples

The sample ChasedSense (22 §13): whether the nearest threat is hunting this animal.

public class ChasedSense : Sense
{
    static readonly IReadOnlyList<string> tokens = System.Array.AsReadOnly(new[] { "no", "yes" });

    public override IReadOnlyList<string> Tokens => tokens;
    protected override string DefaultLabel => "Chased";

    public override int Read(Animal a, SenseContext s)
    {
        var threat = s.NearestAnimal(a, AnimalSet.Threats, s.Vision(a));
        if (threat == null) return 0;
        var t = threat.Value.Animal;
        bool hunting = t.CurrentAction != null && t.CurrentAction.Hunts;
        return hunting && s.CurrentTarget(t) == a ? 1 : 0;
    }

    public override string Write(int token, TextStyle style) =>
        style == TextStyle.V2 ? (token == 1 ? "Something is chasing me." : "Nothing is chasing me.")
                              : $"{Label}: {tokens[token]}.";
}

Remarks

Derive from it, list every token in Tokens, implement Read(Animal, SenseContext), and place the component under a species. The species collects its senses depth-first in its hierarchy: that order (Index) is the order of the tokens in the Observation and of the fragments in the situation text (SENSE-02, SENSE-10).

Lifecycle: Declare(SpeciesBuilder) declares the traits the sense reads (such as "vision"); Initialize() finds stats and other modules and builds the token list; then, on every tick with decisions, the sense phase calls ReadAll(IReadOnlyList<Animal>, SenseContext, Span<int>) for the deciding animals of the species, and the species calls Write(int, TextStyle) to turn each token into text.

A sense only reads. It sees the world as it was at the start of the tick (SENSE-04), asks through SenseContext so hidden and killed animals are never reported (SENSE-06), and draws no random number: the same state gives the same token (SENSE-03). It keeps settings only, nothing per animal.

Each sense multiplies the species' number of possible observations by its token count (SENSE-05): few tokens keep the memo and the answer cache useful.

Remarks

Called by the sense phase, through ReadAll(IReadOnlyList<Animal>, SenseContext, Span<int>), for every animal that decides this tick, and by tools (Observe(Animal, SenseContext)). It must give the same token for the same state, draw no random number, change nothing in the world, and learn about other animals only through s, which leaves out hidden and killed ones (SENSE-03, SENSE-06).

ReadAll(IReadOnlyList<Animal>, SenseContext, Span<int>)

Reads every deciding animal of the species in one call: the batch entry point the sense phase uses (20 §10, ARCH-12). The default calls Read(Animal, SenseContext) for each animal.

Override it only to go faster (a Burst job…). The override must write exactly the tokens Read(Animal, SenseContext) would give, animal by animal (SENSE-31); Read(Animal, SenseContext) stays the readable reference and the test oracle.

Write(int, TextStyle)

Writes a token as the text the brain reads: one fragment of the situation text (SENSE-10).

public virtual string Write(int token, TextStyle style)

Parameters

token int

An index into Tokens.

style TextStyle

The world's text style: V1 terse ("Energy: low."), or V2 first person ("I am hungry and weak.") (SENSE-11).

Returns

string

A sentence ending with a period. The default writes "Label: token." in both styles.

Remarks

The species joins the fragments of its senses with spaces (Describe(Observation, TextStyle)). The text depends on the token only, never on the animal, so the same observation always gives the same text: the answer cache keys on it. Override it for V2 sentences or to state a range in meters (SENSE-12, SENSE-13).
