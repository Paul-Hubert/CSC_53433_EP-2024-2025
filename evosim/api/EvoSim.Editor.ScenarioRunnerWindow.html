Remarks

Open it with Window ▸ EvoSim ▸ Scenario Runner, in Edit mode. Pick a scenario and a variant, edit the seeds (comma-separated) and the length, and press Run: each seed runs through Run(ScenarioAsset, string, int, int?, Action<World>, WaitMode) with a cancellable progress bar, and its one-line summary (ticks, event hash, model calls, run folder) is listed. The run's files go to Logs/EvoSim/runs/<scenario>-<variant>-s<seed>-<time>/.

The scenario's scene must not be open in the editor (WithScene(string, Func<World, string>) refuses it). The Expect line is shown for reading; only the "deterministic" fact is checked, by Run each seed twice.
