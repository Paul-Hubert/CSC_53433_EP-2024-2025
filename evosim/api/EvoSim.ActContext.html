What an action may do in one tick (ACT-06): ask questions about what the animal could sense, and say where it wants to go (an intent) and what to do on arrival (an interaction). It can't move or change any animal itself.

Examples

The grazing part of the reference EatAction:

public override void Act(Animal a, ActContext c)
{
    var food = c.NearestResource(a);                      // within vision, diet-checked
    if (food == null) { c.Search(); return; }             // nothing in sight: search (ACT-04)
    c.WalkTo(food.Value.Position, stopAt: 0f);            // MOVE-04
    c.OnArrival(Interaction.Graze(food.Value));           // applied after moving, within reach (ACT-10)
}

Remarks

The act phase owns one context and reuses it for every animal. For each animal it calls Begin(Animal), then the chosen action's Act(Animal, ActContext), then reads Plan. Afterwards the species' Locomotion moves the animal, and the interaction applies only if the animal is within reach after moving (ACT-10).

The queries (Nearest…, InCover(Animal), IsReady(Animal)) only return what the animal's senses could report: within its vision, never itself, never a killed animal, never an animal hidden from it in cover (ACT-05). In the sequential act orders they see the state left by the animals that acted before; in the simultaneous order, the state at the start of the act phase (ACT-31).

The intent methods (WalkTo, RunTo, RunAwayFrom, WalkAwayFrom, Stay(), Wander(), Search()) replace each other: the last one called is the plan. The two OnArrival methods set the interaction the same way.

Search()

Nothing to act on in sight: wander, counted as searching once per decision (ACT-04).

public void Search()

Remarks

The first call after a decision sets the animal's Searching flag and adds one to its species' Invalid count (the prototype's "invalid"); the next decision clears the flag. Every action that can find nothing should call it rather than Wander().

Wander()

A persistent random walk (MOVE-05): keep the heading; with probability WanderTurnP turn by ±45° or ±90°; blocked, pick a new random heading. Walks. Draws from the species' actions stream.

public void Wander()

Remarks

It turns the current animal's own heading. Without a locomotion it turns with probability 0.25. When the action has nothing to act on, call Search() instead, so that the search is counted (ACT-04).
