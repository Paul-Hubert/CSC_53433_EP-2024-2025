JSON calls to one server with the reference client behaviour (DEC-42): a time-out per try, tries with doubling waits between them, a cap on requests in flight. The API key is read from its environment variable at each call and only sent, never stored or logged (OUT-04).

Remarks

Each HTTP brain and mutator client makes its own (Caller, Caller): nothing is shared between worlds (ARCH-07). It is safe to call from several threads at once; requests above MaxParallel wait for a free place.

A try that times out, gets no answer or gets a retryable status (408, 429, 5xx) is tried again after Backoff, then twice as long, and so on, until Tries are used. Any other error status fails at once.
