A set of species resolved from the food web (SPEC-12): whom an animal flees, hunts or follows.

public enum AnimalSet

Fields

Threats = 0

Species whose diet strikes this one (derived); a cannibal species is among its own threats (SPEC-11).

Prey = 1

Species this one's diet strikes (derived).

Kin = 2

This species: its own animals, never the asking animal itself.

Listed = 3

The species listed on the module that uses the set, by id or display name (flee only from wolves).

Remarks

The World derives threats and prey from the diets once the species are initialized, and again when a species is added during a run (RebuildFoodWeb()); Resolve(Species, AnimalSet, IReadOnlyList<Species>) turns a set into its species.
