Reads and overrides any serialized setting by path (CFG-02): "<GameObject path>/<Component>/<field>", relative to the World, e.g. "Prey/Litter/max", "World/decisionPeriod", "prey/Actions/flee/FleeAction/fleeIntoCover". Names are matched without case; a component is found by its class or a base class, on the GameObject or below it.

Remarks

How a path is read: the last part is the field, the one before it the component, the rest a GameObject path under the World. A GameObject matches by name, or a species by its id or display name. When the full GameObject path has no such component, shorter ones are tried, down to the World itself; the first component found below wins (depth-first). Failing a class name, the component part may be a GameObject's name: the first species module on that GameObject is taken. World/x is the World's own field.

Only serialized fields count (public or [SerializeField], not read-only): what the inspector shows. Values convert from text in the invariant culture: string, int, long, float, double, bool, any enum (by name, any case) and float arrays ([8, 4]).

Remarks

Covers the World, its modules, species, species modules and Edibles that are active and enabled. Keys are <GameObject path>/<class>/<field>; values are numbers, strings, bools, enum names, Unity objects by name, lists, or dictionaries for serialized classes. RunInfo writes it as settings.
