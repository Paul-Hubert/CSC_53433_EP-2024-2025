Remarks

Place it on or under an action: it is bound to that action and labelled with its name (GENE-05), like the prey's eat gene, prey.eat. A gene that belongs to no action (a temperament, say) is marked free and appears under its own label.

Its founder pool is the founder sentences (from the shared AllelePool when one is set, else its own list), plus the neutral allele "No preference." when it has one (GENE-20, GENE-24). Every sentence, founder or mutant, must pass the sentence guards with MaxWords (GENE-22). The contrast pair is used only by brain tests (GENE-23).

Remarks

A founder genome draws each locus uniformly from it, and newcomers below the floor too (POP-03). The World registers the whole pool first, in this order, so founder alleles get the same ids in every run (GENE-21): it must give the same values in the same order every time. The validator reports an empty pool (V-41).
