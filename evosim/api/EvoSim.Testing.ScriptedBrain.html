Class ScriptedBrain

Namespace

A test brain (30 §2): answers from a policy written in the test, or from given rows per (species, observation); counts calls and batches; can answer N Advance calls late, fail, or refuse to mix species. Test code only: the system ships no rule-based brain (owner decision).

Examples

Every animal chooses to mate, whatever it senses:

var w = New(name: "baby age").Ecology(40f, 0f, 0f, regrow: 0f, prey: s => s.LifeRules(40, 0)).ReferencePhases()
    .DefaultBrain<ScriptedBrain>(b => b.Policy = q => ScriptedBrain.Prefer(q.Species, "mate")).Build();

A policy that reads the situation (the scripted prey of R-01): flee a close threat, eat food in sight, mate with a near partner, else rest.

static float[] PreyPolicy(DecisionQuery q)
{
    if (q.Species.Id != "prey") return Brain.Uniform(q.Species.Actions.Count);
    string threat = ScriptedBrain.Token(q, "Predator"), food = ScriptedBrain.Token(q, "Food");
    string kin = ScriptedBrain.Token(q, "Animal");
    string action = threat == "adjacent" || threat == "close" ? "flee"
                  : food != null && food != "none" ? "eat"
                  : kin != null && kin.EndsWith(", ready") ? "mate" : "rest";
    return ScriptedBrain.Prefer(q.Species, action, 0.02f);
}

var w = New(seed).Lab1(prey: 30, predators: 5, randomBrain: false)
    .DefaultBrain<ScriptedBrain>(x => x.Policy = PreyPolicy).Build();

Remarks

For each query it answers, in this order: a failure when FailWhen gives a message; the row in Vectors for the query's species and observation key; the row Policy returns; a uniform row.

Add it with DefaultBrain<T>(Action<T>, string) and keep a reference from the configure callback, or find it with w.GetComponentInChildren<ScriptedBrain>(). Every query it saw is in Seen.

Ask(IReadOnlyList<DecisionQuery>)

Records the batch and answers each query from FailWhen, Vectors, Policy or a uniform row, at once or DelayCalls Advance calls later; each query counts as one model call.

public override BrainAnswer Ask(IReadOnlyList<DecisionQuery> batch)

Parameters

batch IReadOnlyList<DecisionQuery>

The queries the memo and the cache could not answer, at most one per memo key (DEC-32); never empty.

Returns

BrainAnswer

One row or one failure per query, in query order: Now(float[][]) when every row is ready, or Later(int) filled from another thread, then completed.

Remarks

Called on the main thread by the ask-brains phase, once per tick and per batch. Read only the queries: a row must depend on the query alone (DEC-12), and the brain must not change the world (CORE-06). A query it can't answer is marked with Fail(int, string), never answered with a made-up row.
