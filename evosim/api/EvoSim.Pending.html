Remarks

A phase returns one from WaitsFor(TickContext). The World reads IsDone on the main thread: in Responsive mode it comes back on a later frame while the work is not done; in Freeze mode it calls Wait(), which blocks until it is (SPACE-14).

Build one with Done(), Of(Task) (a Task), All(IReadOnlyList<Pending>) (several), or ManualPending. A subclass must make IsDone safe to read from the main thread while the work runs on another, and Wait must never need the main thread to finish (it is blocked).
