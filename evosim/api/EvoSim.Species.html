Examples

A module finds its companions through its species, and a phase loops over the living:

public override void Initialize() => energy = Species.Module<Energy>();

foreach (var s in World.AllSpecies)
    foreach (var a in s.Animals)
        if (!a.IsGone) a[energy.Value] -= 0.1f;

A subclass that only adds a hook (from another assembly the override is protected):

public class LoggedSpecies : Species
{
    protected override void OnBorn(Animal a) => Debug.Log($"{a} joins ({a.Origin})");
}

Remarks

Place a Species under the World, never inside another species (V-01). Everything under it is its configuration (ARCH-01): its SpeciesModule components (senses, actions, genes, stats, rules, diet, locomotion, body…). Within each kind, depth-first hierarchy order is the order: the n-th action found is action n, the n-th sense gives the n-th fragment of the situation text.

The species owns its living animals (Animals): plain data records, in creation order (ARCH-03). The World sets it up at Initialize: it collects the modules and binds each text gene to its action, runs every module's Declare then Initialize, signs it (SPEC-03) and builds its prompt template (PROMPT-01).

Modules reach each other through it: Module<T>() for the one module of a kind, ModulesOf<T>() for all of them.

ComputeSignature()

The signature: a hash of the action, gene and sense orders and tokens (SPEC-03).

public string ComputeSignature()

Returns

string

16 hex digits of a SHA-256 over the action names, gene labels and kinds, and sense labels and tokens, in order.

Remarks

It changes when an action, gene or sense is added, removed, renamed or moved: results and cached answers then change too, and validation warns until the new signature is accepted (V-12).
