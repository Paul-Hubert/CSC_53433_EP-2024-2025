Assets ▸ Create ▸ EvoSim (21 §6): script templates for a new sense, action, gene kind, stat, phase, brain or mutation operator — each with the methods to override and a matching test — and a mutation deck. Scripts go to Assets/Student (with its assembly), tests to Assets/Student/Tests (with a test assembly that sees EvoSim.Testing).

Remarks

In the Project window: Assets ▸ Create ▸ EvoSim ▸ Script ▸ Sense / Action / Gene kind / Stat / Phase / Brain / Mutation operator. A save dialog asks for the class name (the file name); the script Assets/Student/<Name>.cs and its test Assets/Student/Tests/<Name>Tests.cs are written and the script is selected. Each script compiles as it is and does something trivial, with the methods to override; each test builds a small world in code (WorldBuilder) that uses the new class, and checks one fact. Assets ▸ Create ▸ EvoSim ▸ Mutation Deck saves a copy of the reference deck to edit.

The first time, the Student assembly (it sees EvoSim.Runtime, EvoSim.Http and EvoSim.Samples) and the Student.Tests assembly (editor only, with EvoSim.Testing and NUnit) are created.
