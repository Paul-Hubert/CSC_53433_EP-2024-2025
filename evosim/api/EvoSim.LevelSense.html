Remarks

The reference of teaching-path exercise 2 (MyLevelSense, 22 §0). What it does:

  • Tokens, in this order: "low" (0), "medium" (1), "high" (2).
  • Initialize() finds the stat named in the Inspector once, with Species.Declarations.FindStat(stat).
  • Read(Animal, SenseContext) reads the animal's value of that stat (a[value], 0 when the stat is missing) and returns "low" below the low threshold, "high" above the high threshold, else "medium": a value equal to a threshold is medium.
  • Write(int, TextStyle) gives "Energy: low." in V1, and in V2 the Inspector's sentence for the token ("I am hungry and weak.", "I have some energy.", "I am well fed and strong."), or the V1 text when that sentence is missing or empty.
  • The default label is the stat's name with a capital letter ("energy" gives "Energy").
  • Validate(ValidationReport) reports V-31 when the low threshold is above the high one, V-20 when no module declares the stat.

One component per stat: the reference species have one for energy and one for stamina; recipe 22 §2 adds one for thirst with no code.

Read(Animal, SenseContext)

"low" (0) when the animal's stat is below Low, "high" (2) when above High, else "medium" (1). A missing stat reads as 0.

public override int Read(Animal a, SenseContext s)

Parameters

The animal that decides.

s SenseContext

The world as it was at the start of the tick: nearest animals, food, cover, distances, rays.

Returns

int

An index into Tokens.

Remarks

Called by the sense phase, through ReadAll(IReadOnlyList<Animal>, SenseContext, Span<int>), for every animal that decides this tick, and by tools (Observe(Animal, SenseContext)). It must give the same token for the same state, draw no random number, change nothing in the world, and learn about other animals only through s, which leaves out hidden and killed ones (SENSE-03, SENSE-06).

Write(int, TextStyle)

V1 "Energy: low."; V2 the Inspector's sentence for the token, or the V1 text when it has none (SENSE-11).

Parameters

token int

An index into Tokens.

style TextStyle

The world's text style: V1 terse ("Energy: low."), or V2 first person ("I am hungry and weak.") (SENSE-11).

Returns

string

A sentence ending with a period. The default writes "Label: token." in both styles.

Remarks

The species joins the fragments of its senses with spaces (Describe(Observation, TextStyle)). The text depends on the token only, never on the animal, so the same observation always gives the same text: the answer cache keys on it. Override it for V2 sentences or to state a range in meters (SENSE-12, SENSE-13).
