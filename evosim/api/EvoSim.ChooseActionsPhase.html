Waits for the brains (TICK-03), stores fresh answers in the memo and the cache (never a failure, DEC-34), and draws each deciding animal's action with its species' sampling stream after the temperature (DEC-20, RAND-03). A failed answer stops a strict run cleanly; otherwise it becomes a uniform row and is counted (DEC-40).

Remarks

Third phase of the reference tick, after Ask brains (V-08) and before Act. It is the phase the tick waits at while the brains think: in the Freeze wait mode the main thread blocks, in the Responsive mode the tick resumes here on a later frame (SPACE-14). Either way the result is the same.

An animal that shares another's key (DEC-32) takes that animal's row. Every deciding animal gets a new action, its searching and bred-this-period flags are cleared (DEC-03), and its observation, situation and probabilities are kept for the inspector (DEC-21).

When the draw picks an overlay (ACT-07), a second draw from the same stream picks the carrier among the other actions, in proportion to their probabilities (DEC-20). Species without overlays draw exactly once.

WaitsFor(TickContext)

The brains' answers to this tick's batches that are not in yet, or null when all are in (or nothing was sent).

public override Pending WaitsFor(TickContext t)

Parameters

t TickContext

The current tick's context.

Returns

Pending

What must be done before Run(TickContext), or null when nothing is awaited. A Pending already done lets the phase run at once.

Remarks

The World asks before every attempt to run the phase: in Responsive mode, again at every Advance call while the tick waits. Return the same work for the same tick, and don't change the world or draw random numbers here, so both wait modes give the same run (SPACE-14, RAND-11).
