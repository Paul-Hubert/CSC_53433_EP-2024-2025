Remarks

The World makes a new one at each run (Alleles). It registers the founder pools first, in pool order, so founders get the same ids in every run (GENE-21); founders and newcomers are registered as they are drawn, and the hatch phase registers each mutant.

Sentences are compared after collapsing spaces, numbers at the gene's Decimals: registering a value already known at that locus returns the existing allele, with its first origin and lineage.
