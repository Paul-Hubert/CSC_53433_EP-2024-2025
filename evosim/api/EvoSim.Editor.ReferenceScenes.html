Class ReferenceScenes

Namespace
EvoSim.Editor
Assembly
EvoSim.Editor.dll

Builds the reference content (20 §2, §7; 09 §3): the allele pools from the prototype's pool files, the module prefabs (Modules/), placeholder bodies, and the scenes Lab1_Small, Lab1_Full, HideVsFlee, ThreeSpecies, Terrain_Locomotion and Sandbox. The scenes are then the configuration (ARCH-01): edit them, not this builder, unless the reference itself changes. Scenes are opened additively from an empty file, so the editor's own open scene is never touched.

Remarks

Menus: EvoSim ▸ Build Reference Scenes (BuildAll()) rebuilds everything and overwrites the six scenes, the pools, the module prefabs and the scenario assets; EvoSim ▸ Reference ▸ Update Reference Scenes (UpdateReferenceScenes()) only brings the saved scenes to the current reference settings.

The same builder makes the World of GameObject ▸ EvoSim ▸ New World (NewWorld(string, float)), so a new world and the reference worlds have the same tree.

Methods

BuildAll()

EvoSim ▸ Build Reference Scenes: rebuilds the allele pools, the module prefabs and bodies, the six reference scenes and the scenario assets, overwriting them, then saves the assets.

[MenuItem("EvoSim/Build Reference Scenes")]
public static void BuildAll()

Remarks

Course staff only, when the reference itself changes: the scenes are the configuration (ARCH-01), and a rebuild erases any edit made in them. Scenes open in the editor should be closed first.

UpdateReferenceScenes()

Brings the saved reference scenes to the builder's reference without rebuilding them: the reference decision period (DEC-01, owner 2026-10-11) and a staggered DecisionSchedule in every species' Life group (DEC-04, owner 2026-10-10); a species that has a schedule keeps it.

[MenuItem("EvoSim/Reference/Update Reference Scenes")]
public static string UpdateReferenceScenes()

Returns

string

One line per scene: what changed, nothing, or open in the editor, skipped.

Remarks

EvoSim ▸ Reference ▸ Update Reference Scenes. A scene open in the editor is skipped; the others are opened additively, changed, saved when something changed, and closed. The result is logged.
