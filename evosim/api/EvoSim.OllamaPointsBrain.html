Remarks

The server is Ollama on http://localhost:11434 (/api/chat, and /api/tags for the connection test and the digest), with two requests in flight by default. The model's tag and digest are part of the answer cache's keys (DEC-33): pin the digest in the Inspector, or it is asked from the server when the run begins.

A task that ends when every request has its row or its failure.

Remarks

Runs on the thread pool: use no Unity API here, and await with ConfigureAwait(false). Don't call Complete(): the base does it when this task ends. An exception thrown here fails every request still without a row, with its message.

Begin()

Asks Ollama for the model's digest, once, when no digest is pinned and a species uses this brain. It blocks the main thread for at most about 5 s; an unreachable server gives unknown.

public override void Begin()

Remarks

Not called when the editor only validates. Draw random numbers from a named stream, e.g. World.Random.Get("world/" + ServiceName) for the map (RAND-04).
