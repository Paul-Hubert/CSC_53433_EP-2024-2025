Remarks

Tokens "young" (0) and "adult" (1); an animal is adult once its age in ticks reaches its "maturity" trait. Texts: V1 "Age: adult.", V2 "I am an adult." / "I am young.". Reference label "Age".

"Age".

Tokens

Every token this sense can return, "none" included, in a fixed order: Read(Animal, SenseContext) returns an index into this list. Fixed before the run (SENSE-01); its length is the sense's factor in the observation space (SENSE-05).

public override IReadOnlyList<string> Tokens { get; }

Build it in a field or in Initialize(), never during a run. A static list shared by every instance should be read-only.

Methods

Declare(SpeciesBuilder)

Declares the "maturity" trait, in ticks, with this sense's setting as its default; if another module declared it first, its declaration counts.

public override void Declare(SpeciesBuilder b)

Parameters

b SpeciesBuilder

The species' declarations: call DeclareStat(string, StatStart, float, float, TraitId) and DeclareTrait(string, float, float, float, bool), and keep the ids they return.

Remarks

Called before any module's Initialize: don't look up other modules here. Two modules may declare the same name: they get the same id, and the first declaration counts (V-38 if they differ).

Read(Animal, SenseContext)

"adult" (1) when the animal's age in ticks is at least its maturity trait, else "young" (0).

public override int Read(Animal a, SenseContext s)

Parameters

a Animal

The animal that decides.

s SenseContext

The world as it was at the start of the tick: nearest animals, food, cover, distances, rays.

Returns

int

An index into Tokens.

Remarks

Called by the sense phase, through ReadAll(IReadOnlyList<Animal>, SenseContext, Span<int>), for every animal that decides this tick, and by tools (Observe(Animal, SenseContext)). It must give the same token for the same state, draw no random number, change nothing in the world, and learn about other animals only through s, which leaves out hidden and killed ones (SENSE-03, SENSE-06).

Write(int, TextStyle)

V1 "Age: young." / "Age: adult."; V2 "I am young." / "I am an adult.".

public override string Write(int token, TextStyle style)

Parameters

token int

An index into Tokens.

style TextStyle

The world's text style: V1 terse ("Energy: low."), or V2 first person ("I am hungry and weak.") (SENSE-11).

Returns

string

A sentence ending with a period. The default writes "Label: token." in both styles.

Remarks

The species joins the fragments of its senses with spaces (Describe(Observation, TextStyle)). The text depends on the token only, never on the animal, so the same observation always gives the same text: the answer cache keys on it. Override it for V2 sentences or to state a range in meters (SENSE-12, SENSE-13).
