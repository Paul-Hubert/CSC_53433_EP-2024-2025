Examples

The test brain MemoryBrain: uniform rows, but not memoizable, so it sees every deciding animal's id.

public class MemoryBrain : Brain
{
    public readonly List<int> AnimalIds = new List<int>();

    public override string Id => "memory";
    public override bool Memoizable => false;

    public override BrainAnswer Ask(IReadOnlyList<DecisionQuery> batch)
    {
        var rows = new float[batch.Count][];
        for (int i = 0; i < batch.Count; i++)
        {
            AnimalIds.Add(batch[i].AnimalId);
            rows[i] = Uniform(batch[i].Species.Actions.Count);
        }
        return BrainAnswer.Now(rows);
    }
}

Remarks

A brain is a world service: place the component under the World's services, then pick it as the World's default brain or as one species' brain (DEC-13). Derive from it, give it an Id and implement Ask(IReadOnlyList<DecisionQuery>); override the limits (MaxActions, MaxPromptTokens, AcceptsAttachments, CanMixSpecies), which validation checks against every species that uses the brain before the run (DEC-14, V-10, V-11, V-51). A brain behind a model server derives from HttpBrain instead, which adds retries, time-outs and parallel requests.

Once per tick the ask-brains phase builds one DecisionQuery per deciding animal, answers what it can from the memo and the answer cache, and calls Ask(IReadOnlyList<DecisionQuery>) once with the rest (once per species when CanMixSpecies is false). The choose-actions phase waits for the BrainAnswer, checks each row, stores good rows in the memo and the cache, and draws the action.

What a brain must keep: one row per query, in query order, one entry per action of the query's species in the species' action order, every entry ≥ 0, summing to 1 ± 1e-6 (DEC-11); the same query always gives the same row (DEC-12), unless Memoizable says otherwise; and it never moves an animal or changes the world (CORE-06).

Ask(IReadOnlyList<DecisionQuery>)

Answers a batch of queries (DEC-11). Fast brains fill the answer at once; HTTP brains later.

public abstract BrainAnswer Ask(IReadOnlyList<DecisionQuery> batch)

Parameters

batch IReadOnlyList<DecisionQuery>

The queries the memo and the cache could not answer, at most one per memo key (DEC-32); never empty.

Returns

BrainAnswer

One row or one failure per query, in query order: Now(float[][]) when every row is ready, or Later(int) filled from another thread, then completed.

Remarks

Called on the main thread by the ask-brains phase, once per tick and per batch. Read only the queries: a row must depend on the query alone (DEC-12), and the brain must not change the world (CORE-06). A query it can't answer is marked with Fail(int, string), never answered with a made-up row.
