Examples

The reference predator's diet, set from code as the reference scenes do:

var diet = foodObject.AddComponent<Diet>();
diet.Set("prey", "carcass:prey");     // strike prey animals, scavenge their carcasses
diet.SetKillChance(0.5f);              // the default of the hunter's kill.chance trait

Remarks

Whether something is eaten is decided on both sides (SPEC-13): the eaten thing carries an Edible, which says how much energy it gives, and the eater's diet lists it. Each entry names a resource layer (grazed), a species by id or display name (struck), carcass:<species> (scavenged) or egg:<species> (eggs eaten), with an energy scale.

The entries are resolved by name in Declare(SpeciesBuilder) and Initialize(), and again when a species is added during a run (RebuildFoodWeb()). The World derives the food web from Striking(Species): the species a diet strikes are its prey, and it is their threat (SPEC-12). The interaction resolver asks Grazing(ResourceLayer), Striking(Species), Scavenging(Species) or EatingEggs(Species) before every meal, then EnergyFrom(Animal, EdibleTarget, float) for its energy and KillChanceAgainst(Animal, Animal) for a strike's odds.

All six are virtual: derive from Diet to make meals depend on the eater or the prey. The species' modules find it with Species.Module<Diet>(), so keep one diet per species.
