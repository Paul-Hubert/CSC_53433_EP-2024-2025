Class Ground

Answers, for any point, its height and whether it is walkable (SPACE-04), inside a bounded rectangle with hard borders (SPACE-03). It also owns the world's distance function (SPACE-02): every module measures through it.

Examples

// The Lab 1 ground (FlatGround): the three questions every ground answers.
public class FlatGround : Ground
{
    [SerializeField, Min(1f)] float width = 192f;
    [SerializeField, Min(1f)] float depth = 192f;

    public override Rect Bounds => new Rect(0f, 0f, width, depth);
    public override float Height(Vector3 p) => 0f;
    public override bool IsWalkable(Vector3 p) => Inside(p);
}

// A flat ground with a round pond that animals can't enter (from EvoSim's test probes).
public class PondGround : FlatGround
{
    public Vector3 PondCenter = new Vector3(10f, 0f, 10f);
    public float PondRadius = 3f;

    public override bool IsWater(Vector3 p) => Flat(p, PondCenter) < PondRadius;
    public override bool IsWalkable(Vector3 p) => base.IsWalkable(p) && !IsWater(p);

    static float Flat(Vector3 a, Vector3 b) => new Vector2(a.x - b.x, a.z - b.z).magnitude;
}

Remarks

One ground per World, under it (reference: the "Ground" GameObject). The World initialises it before every other service, since layers and cover are laid on it, and finds it as Ground.

Derive from it and implement Bounds, Height(Vector3) and IsWalkable(Vector3); override IsWater(Vector3) and NearestWater(Vector3, float) for water, Distance(Vector3, Vector3) for path length. The answers must not change during a run, and IsWalkable(Vector3) is false outside Bounds. All walkable ground should be connected (SPACE-05). The movement helpers (SlideTo(Vector3, Vector3), SideStep(Vector3, float, RandomStream)) keep every animal on walkable ground (MOVE-02).
